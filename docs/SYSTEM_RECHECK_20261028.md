# IRIS2 최종 재점검 — 2026-10-28

수정 완료: 설비 6대의 현재 설계 튜브 총수와 화면·허용수량 기준 통일, 극소 부식속도 및 날짜 범위 초과 처리, 서버·브라우저 예측일 1일 차이 해결, 실제 Plugging일 유지, 그래프 초록·주황·빨강 표시 및 배율 연동 보완.

계산: (공칭두께 × 0.4 - 현재감육량) / 적용 부식속도로 잔여기간을 계산하며 최신 검사 감육량을 현재 계산 기준일의 값으로 간주한다. 기본 허용률은 일반 20%, Critical 10%이고 허용수량은 소수부를 버린다. 누적 수량이 허용수량을 처음 초과하는 연도를 수명 도달 연도로 사용하며 잔여수명은 음수가 되지 않는다. 예측기간의 소수 일수는 내림해 서버와 브라우저를 일치시켰다. 도움말에 수식과 가정을 반영했다.
