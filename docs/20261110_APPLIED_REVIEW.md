## 5. QR 관련 메뉴와 버튼 — 최종 변경 지시 반영

원문 “전체 숨김”은 이후 추가 지시 “관리자에게만 메뉴 표시”로 대체했다. 현재 구현은 다음과 같다.

| 사용자 조건 | 운영 현황 QR 검색·읽기 | 스캐너 모달·JS | 상세 QR 간편조회 |
|---|---|---|---|
| 관리자 + 열교환기 조회 권한 | 표시 | 포함 | 표시 |
| 일반 사용자 | 숨김 | 제외 | 숨김 |
| 비로그인 | 메뉴 비노출 / 기존 로그인 보호 | 비노출 | 비노출 |
| 열교환기 조회 권한 없음 | 숨김 | 제외 | 숨김 |

- 적용 위치: templates/dashboard.html:34,73,98 및 templates/exchanger_detail.html:6.
- 공통 조건: current_user and current_user.is_admin and can_screen('EXCHANGERS').
- 관리자/일반 사용자별 대시보드 버튼·모달·스캔 스크립트 표시를 시험했다. 상세 액션은 관리자·일반·비로그인·권한 없음 조합을 시험했다.
- 기존 자연어 조회의 QR 요약 링크는 일반 열교환기 상세 링크로 바뀌어 QR 우회 진입 메뉴로 남지 않는다.
- QR 기능·기존 경로는 유지한다. **이 변경은 메뉴 노출 제어이며, QR 직접 URL을 관리자 전용으로 새로 제한한 것은 아니다.** 기존 인증·화면 접근 권한을 그대로 따른다.
- QR_UI_ENABLED 설정은 현재 표시 조건에 필요하지 않다. 운영 config 수정은 없다.

판정: **원문 그대로의 전체 비노출과는 다르지만, 최종 사용자 지시 기준으로 적용 확인.**

## 실제 실행 환경에서 미확인인 사항

이번 점검에서도 http://127.0.0.1:4824/api/health 및 /login 연결은 URLError로 실패했다. 이것만으로 서버 중지 원인이나 방화벽 문제를 확정할 수 없다. 실행 서버 재시작·운영 배포는 수행하지 않았다.

따라서 다음은 통과로 판정하지 않는다.

1. 현재 운영 서버가 이 소스로 실행되고 있는지.
2. 실제 로그인 성공과 사용자 권한별 전체 화면 이동.
3. E-131D의 실제 PLUGGED 수량·기준 도달 수량을 동일 시점의 DB와 상세·튜브 관리·QR에서 대조하는 확인.
