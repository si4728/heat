# Text-to-SQL 검사 보고서 조회

2026-11-17 · VCM1·VCM2

Text-to-SQL 질문창에 `E-111의 2025년 IRIS 검사 보고서 PDF 보여줘`를 입력하고 SQL 생성 버튼을 누르면 보고서 링크 목록을 표시한다. PDF 요청은 로컬 모델이나 생성 SQL을 실행하지 않고 기존 MariaDB 검사 이력과 PDF 페이지 연결을 사용한다.

- 설비 코드·전체 태그·숫자 설비 코드 또는 화면에서 선택한 설비/공정을 적용한다. 질문의 설비와 선택 범위가 충돌하면 오류를 표시한다.
- 기간을 생략하면 대체되지 않은 전체 검사 이력, `최근 보고서`는 최신 날짜의 모든 회차, 연도·기간은 해당 기간의 회차를 조회한다. 지정 회차도 해당 설비 소속인지 검사한다.
- PDF 링크는 기존 `/inspections/<검사 ID>/pdf#page=<페이지>`를 사용한다. 페이지 연결이 없으면 첫 페이지부터 열고 이를 목록에 표시한다. 파일이 없으면 링크를 생성하지 않는다.
- TEXT_TO_SQL·INSPECTIONS 조회 권한과 CSRF 검사를 유지한다. 파일 경로는 응답에 포함하지 않는다. 최대 100개 링크를 표시한다.
- `보고서 감육률 요약` 등 수치 분석 질문은 기존 분석 경로로 처리한다. PDF 본문을 새로 요약하거나 파일을 생성하는 기능은 아니다.

검증: 질문/설비/기간/회차/누락 파일/권한 회귀시험 및 실제 MariaDB의 E-111 2025년 검사 연결, PDF 부분 응답의 헤더와 파일 서명 확인.
