# IRIS2 반응형 UI 재점검 — 2026-10-29

## 변경 내용

- 공통 반응형 CSS를 모든 기본 레이아웃에 적용하고 최종 테마 이후 로드한다.
- 카드·입력폼은 가용 너비에 따라 열 수를 변경하며 상단 메뉴와 제목은 자연스럽게 줄바꿈한다.
- 좁은 화면의 메뉴는 2열로 배치하고 펼친 그룹은 한 행 전체를 사용한다. 접기·펼치기 기능은 유지한다.
- 표·설비 정보·Map의 자체 스크롤은 유지하고 페이지 전체 가로 넘침을 제거한다.
- 정밀분석의 좁은 화면 글자 크기를 개선하고 Map 높이를 화면 높이에 맞춘다.
- 모달 최대 높이는 동적 화면 높이를 사용하고 긴 내용은 내부에서 스크롤한다. 빈 링크를 숨기고 확인 버튼 크기를 유지한다.
- Tube Map 도구 모음의 이동 사유 입력란 너비 초과를 수정한다.
- 인쇄 전용 레이아웃에 영향이 없도록 신규 CSS는 화면 매체에 한정한다.

검증 화면: 대시보드, 정밀분석, 설비 상세·목록·입력, 검사 목록·튜브 이력·계획, 정비, 데이터 입력 현황, PDF·OCR, 사용자, JSON 적재, 조직 코드, 백업, API 510, 잔여수명 Simulation, Tube Map.
