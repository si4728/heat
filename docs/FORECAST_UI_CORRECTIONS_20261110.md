# 2026-11-10 추가 개선사항 반영

이번 지시는 이전 QR 관리자 노출 지시보다 우선한다. QR 검색·QR-code 읽기·QR 간편조회는 관리자와 일반 사용자 모두 기본 비노출로 복귀했다. 기능·라우트는 유지하며 운영 config는 변경하지 않았다. 향후 명시적으로 기능을 다시 켜는 경우에도 관리자 및 열교환기 권한 조건을 유지한다.

## 1. 예측률 분모 명시

독립 예측·상세·QR·보고서·정밀 분석에서 공유 템플릿 prediction_coverage.html로 범위를 표시한다.
- 전체 사양 대비 예측 가능: 5/52개, 9.6%.
- 개별 등록 대비 예측 가능: 5/5개, 100.0%.
- 미등록·평가 제외: 47개. 미등록과 등록 중 예측 제외를 추가로 구분한다.
- 사양 수량 미확인 또는 등록 수량 0이면 비율을 임의로 100%로 표시하지 않는다.
- 집계 가능한 예측 데이터에는 실제 완료·이미 기준 도달된 Tube도 포함됨을 설명한다.

위 수치는 시험 사례이며 실제 DB를 다시 조회한 수치가 아니다.

## 2. 잔여수명 상태 표현 통일

life_display.html의 공유 매크로로 상세·QR·독립 예측·보고서의 LIMIT_NOT_REACHED를 “가용 데이터에서 한도 미도달”로 표시한다. 정밀 분석 JS와 대시보드의 해당 상태도 같은 문구를 사용한다. 데이터 부족은 산정 불가로 구분하고 숫자 0년은 그대로 유지한다. '-년'이나 '예측기간 내 미도달'로 대체하지 않는다.

현재 코드의 forecast_end_year는 그래프 표시 종료 연도만 제어한다. 한도 판정은 가용 예상일 전체를 사용하므로 “예측기간”으로 제한됐다고 표현하지 않는다. 실제 그래프 시작·종료 연도를 안내하고 입력 이름도 “그래프 표시 종료 연도”로 변경했다. 정밀 분석 그래프는 현재 코드대로 기준 연도부터 25년 후까지 표시하며 그 종료 연도를 별도로 전달한다.

## 3. 이미 기준 도달한 Tube의 날짜 표시

서버 예측 행에 최근 검사 감육률의 기준 도달 여부를 명시한다. 상세 표와 정밀 분석의 선택 Tube 표시는 기준 도달 시 다음 문구를 사용한다.

“최근 검사에서 기준 도달 확인 — 실제 도달일 미상”

2026-11-10 같은 계산 기준일은 실제 도달일로 표시하지 않는다. 미래 Tube는 날짜와 “예상일”을 함께 표시하고 실제 PLUGGED 상태는 실제 완료로 구분한다. 내부 계산용 예상일과 누적 계산은 변경하지 않았다.

## 4. QR 진입 숨김

대시보드 버튼·모달·스캔 스크립트와 상세 QR 간편조회 링크는 기본값 false인 QR_UI_ENABLED 조건으로 제외한다. 관리자도 기본적으로 보이지 않는다. 기존 QR 화면 직접 URL은 기존 인증·권한을 유지한다. 메뉴 숨김과 라우트 차단은 별개다.

## 검증 및 한계

- 관련 Python 시험 117건 통과. 레이아웃 조정 뒤 화면 관련 시험 17건 재실행 통과.
- JavaScript 연도별 Plugging, Critical 한도, Text-to-SQL 링크 회귀시험과 변경 JS 구문 검사 통과.
- 실제 템플릿과 CSS/JS에 시험 데이터를 공급해 8개 화면 변형 × 3개 너비(1440/768/390px) = 24개 조합의 렌더링을 검사했다.
- 4개 예측 화면에서 같은 5/52, 5/5 분모와 같은 상태 문구를 확인했다. 상세의 기준 도달 5개 행에 실제 도달일 미상 문구를 확인했다.
- 추가 증거: reports/ui_usability/20261110-corrections/의 validation.json, tests.log, 화면 PNG.
- 실제 서버 브라우저 연결 및 E-131D 실제 DB 재조회는 이번 작업에서 수행하지 않았다. 운영 서버 배포·재시작도 수행하지 않았다.
- DB/config 수정 없음. 원래 iris 수정 없음.

## 이관

변경 소스와 신규 공유 템플릿을 이관/소스/에 반영하고 manifest 해시를 갱신했다. 서비스 코드 변경이 있으므로 운영 적용 시 웹 앱 재시작이 필요하다. 서비스·템플릿·JS/CSS를 함께 반영하고 캐시 버전이 갱신된 base/precision/QR 템플릿을 포함해야 한다.

## Plugging 범위 및 검사 기준일 추가 명시

- 공통 수량 안내: “예측 가능한 등록 튜브 중 향후 추가 도달 대상 0개이며, 미등록 47개는 평가에서 제외됩니다.” 수량은 실제 계산 결과와 사양/등록 데이터에서 동적으로 표시한다. 미등록 수량이 없거나 미확인이면 그에 맞게 안내한다.
- 상세·QR의 “물리 튜브/물리 Tube” 표시는 “개별 등록 튜브”로 변경한다. 전체 사양 수량은 기존 분모 안내와 구분한다.
- 설비 최근 검사일과 계산 기준일을 각각 표시한다. 기준 도달은 각 Tube의 최근 검사값에 따른 판정이며 실제 작업 완료나 계산 기준일의 재측정 결과를 뜻하지 않음을 설명한다. 특정 설비 날짜를 코드에 고정하지 않는다.
- 정밀 분석의 부식속도 슬라이더로 향후 수량이 바뀌면 범위 안내도 함께 갱신한다.
- 시험 데이터의 최근 검사일 2020-10-24 / 계산 기준일 2026-11-10, 미등록 47개, 향후 0개 안내를 상세·QR·독립 예측·보고서에서 확인했다.
- “가용 데이터에서 한도 미도달” 정의 및 공통 잔여수명 표시는 유지한다. 상세·QR에 '-년'을 다시 사용하지 않는다.
- 검증: 관련 Python 50건, 연도별 Plugging 및 Critical 한도 JS 회귀시험 통과. 모의 데이터 기반 24개 브라우저 조합 통과. 실제 서버 및 E-131D DB 재조회는 수행하지 않았다.
- DB/config/계산식 변경 없음. 수정 소스 5개와 이관 manifest를 동기화했다.
