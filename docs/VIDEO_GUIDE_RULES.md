# IRIS2 업무 화면 안내 영상 제작 기준

사용자 요청 반영 기준일: 2026-10-26.

- 데이터 점검 관련 메뉴를 소개하지 않는다. DB 상태 점검, 품질 이슈, PDF·OCR 검토와 데이터 품질·ML 점검 등 관리·검증 기능은 업무 안내 범위에서 제외한다.
- 소개하는 메뉴는 실제 앱에서 열고, 설명하는 기능을 직접 클릭하거나 조작한다. 대표 화면 하나로 다른 메뉴의 실행 결과를 대신하지 않는다.
- 클릭 전 위치와 클릭 후 결과를 연결해 보여주고, 입력값·조건·단위·결과를 구체적으로 설명한다.
- 정밀 분석을 중심으로 설비 선택, Map·표 선택 연동, 격자·축, 패널 조절, 두께 이력, 부식속도, 배율별 예상, 잔여수명 항목과 3D 연결을 충분히 다룬다.
- 저장·수정·상태 전환은 인증·CSRF를 유지한 격리 테스트 스키마에서만 시연한다. 시연값을 실제 설계·운전 기준으로 소개하지 않는다.
- 원천 측정값, 시뮬레이션 가정, 실제 완료 기록을 구분한다. 한도 미도달을 무한 수명이나 운전 승인으로 설명하지 않는다.
- 실제 조작 전후 캡처를 편집한 장면과 연속 동작 캡처를 구분한다. 정지 화면 편집을 실시간 연속 녹화라고 표기하지 않는다.
- 영상 전체 디코딩과 표본 장면의 한글·자막·화면 잘림을 확인하고 메뉴별 대본·클릭 내역을 함께 제공한다.
