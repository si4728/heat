# 검사 표본 기반 최대 감육률 추정

2026-11-12 고객 개선 요청서의 5번 항목을 구현했다. 적용 대상은 VCM1·VCM2이며 정밀 분석과 열교환기 상세에 실측 최대값과 전체 추정 최대값, 최초 Plugging 기준 도달 예상 연도, Plugging 20% 도달 예상 연도를 함께 표시한다. DB 테이블·필드 추가나 원본 측정값 수정은 없다.

## 계산 방법

최근 유효 검사 한 회차의 튜브별 유효 감육률을 오름차순으로 정렬한다. 다른 연도나 다른 보고서의 표본을 합치지 않는다. 현재 번들·현재 설치 이력만 사용하고 대체된 보고서와 무효 측정은 제외한다. 최신 보고서에 유효 측정이 없으면 과거 표본으로 자동 대체하지 않는다.

표본 수를 n, 전체 튜브 수를 N, 오름차순 감육률을 x_i로 둔다.

1. `F_i = (i - 0.3) / (n + 0.4)`.
2. `y_i = -ln(-ln(F_i))`.
3. 감육률을 종속변수로 `x = mu + beta * y` 최소제곱 직선 회귀를 한다.
4. 전체 최대 추정은 `mu + beta * [-ln(-ln(1 - 1/N))]`로 계산한다.
5. 상위 20% 경계값은 `mu + beta * [-ln(-ln(0.8))]`로 계산한다. `1.50`으로 중간 반올림하지 않는다.
6. 추정 감육률은 0~100%로 제한하며, 전체 추정 최대값은 실제 측정 최대값보다 작게 적용하지 않는다. 제한 전 값과 적용 여부도 반환한다.
7. 사용연수는 설치·교체 기준일부터 최근 검사일까지의 실제 일수 / 365.2425로 계산한다.
8. `기준 도달일 = 최근 검사일 + (판정 감육률 - 추정 감육률) / (추정 감육률 / 사용연수)`로 계산한다. 날짜 계산에서는 소수 일수를 버리고 그 날짜의 연도를 표시한다.

회귀계수·R²·표본 수·검사일·설치 기준일·보고서를 화면에 표시한다. R²는 적합도를 보여주는 참고값이며 운전 승인 기준이나 별도의 통계적 신뢰 수준으로 사용하지 않는다.

## 전체 수량 및 예외 처리

- 전체 튜브 수는 기존 기본 예측과 동일하게 현재 사양의 `tube_count`를 사용한다. 보고서 전체 수량과 다르면 두 수량과 사용한 기준을 화면에 표시한다. E-104B는 양쪽 모두 52본이다.
- 유효 표본이 10본 미만이면 **표본 부족**을 표시하고 통계 추정을 적용하지 않는다. 기존 실측 튜브별 예측은 유지한다.
- 전체 수량 누락 또는 표본 수보다 작은 수량, 동일 감육률만 있는 표본, 최신 검사 회차 중복, 서로 다른 설치·교체 시점이 섞인 표본은 추정 미적용 사유를 표시한다.
- 설치일이 없거나 검사일 이후이면 감육률 회귀 결과는 표시할 수 있어도 도달 연도는 산정하지 않는다. 설치 연도만 있으면 기존 정책에 따라 7월 1일을 사용하고 이를 표시한다.
- 이미 추정 감육률이 판정 기준 이상이면 **검사일 기준 추정상 도달**로 표시한다. 실제 측정값이 기준 이상인 경우의 **검사 시 기준 도달**과 구별하며 알 수 없는 최초 도달 날짜를 만들지 않는다.

## 기존 예측과 구분

새 항목은 전체 튜브의 통계 추정이며, 실제 Plugging 완료 기록이 아니다. 20% 도달은 80백분위 경계 감육률이 판정 기준에 도달하는 시점이다. 기존 일반 20%·Critical 10% 수량 초과 계산이나 대시보드의 실측 튜브 최초 도달을 덮어쓰지 않는다.

새 표의 실측 최대값 비교 연도도 그림 5의 검사일·설치 후 평균 기준으로 계산한다. 기존 튜브별 예측은 현재 계산 기준일을 사용하는 기존 산식을 유지하므로 두 방식의 연도가 다를 수 있다. 화면에서 별도의 추정 기준을 명시한다. 튜브별 부식속도 배율 슬라이더는 기존 실측 예측에 적용하며 이 별도 표본 추정에는 적용하지 않는다.
