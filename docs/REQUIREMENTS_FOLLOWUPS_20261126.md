## 선택·판정 기준

순위는 과거 이력 전체의 최고 감육률에서 **튜브별 최근 유효 측정 중 최대값**으로 변경했다. 부분 검사, 대체된 검사, 유효하지 않은 결과·품질, 기준일 이후 검사, 날짜 없는 검사, 현재 설치 이전 이력을 분석과 동일하게 제외한다. 같은 날짜의 같은 튜브는 최대 감육률, 동일값이면 결과 번호로 안정적으로 선택한다. 해당 검사에 감육률이 공란이면 과거 값을 되살리지 않는다. 유효값이 없는 설비는 0%로 만들지 않고 미등록으로 표시한다.

순위의 대표 튜브·측정일·보고서·최소두께도 선택된 실제 결과에서 함께 가져온다. 유효 측정 튜브 수는 최근 선택 결과의 수, 결과 수는 적격 이력 결과 수다. 서로 다른 검사에서 측정된 튜브가 섞일 수 있으므로 ‘가장 최근 한 회차의 최대값’과는 구분한다. 표시 기준은 순위 화면에 명시했다. 원본 이력과 보고서는 유지한다.

분석 선택 목록은 두 자리 소수와 미등록 표시를 사용한다. 기존 화면 구성과 색상은 유지했다. 공정 선택지는 PE·VCM1·VCM2로 한정했다.
