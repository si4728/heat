# 고객 미반영 항목 적용 결과

후속 재점검에서 확인한 미완료·경계 오류는 [2026-11-26 요구사항 재점검](REQUIREMENTS_RECHECK_20261126.md)을 확인한다. 이 문서의 기본 구현 확인을 요구사항 전체 합격으로 해석하지 않는다.

2026-11-24. 적용 범위는 PE·VCM1·VCM2이며, 운영 웹 서비스는 중지 상태다. 별도 Text-to-SQL 화면을 만들지 않았다.

## 실제 로컬 적용과 검증

- 적용 전 로컬 전체 MariaDB 논리 백업 생성. 백업·원본 PDF·실행 결과·화면 캡처는 로컬 보관하며 Git에 포함하지 않는다. 이번 백업 파일 자체의 전체 복원 시험을 수행했다고 주장하지 않는다.
- 실제 운영 DB에는 검증한 12개 보정 필드와 `tube_plugging_event`, `customer_correction_event` 및 변경 방지/캐시 revision 트리거를 적용했다. 보정 재실행 계획은 0건이다.
- SELECT 전용 계정으로 실제 DB를 확인했다. 구간 집계는 **403대 = 15년 초과 65대 + 5년 초과~15년 이하 10대 + 5년 이하 14대 + 산정 불가 29대 + IRIS 미실시 285대**다. 검사·추정 활성화로 이전 ‘표시만 재분류’ 수량과 달라졌다.
- PE 검사 이력 10대의 검사일·표본 수·측정 최대값을 확인했다. E-341 10본 2.77mm, E-222 현재 수량 179본, E-811 2020-10-24와 E-222 분석 화면 진입을 확인했다.
- 관련 자동 시험 254건 통과: Text-to-SQL 199, 보정/구간 계산 9, 정비 API 권한 3, 표본 추정 15, 대시보드 구간 9, 감육속도 8, 대기열 3, 접근 감사 8건.
- 실제 브라우저에서 임시 시험 서버·복제 MariaDB에 연결하여 PE 수명 조건 조회 5대, 구간·사유, Map 2본 완료, Plugged 상태·완료 수량, 취소 후 복원 및 4개 이력을 확인했다. 1440/768/390px에서 가로 넘침을 확인했다. 종합 의견 모델 응답만 시험용으로 대체했으며 실제 모델 부하 시험과 구분한다.
- 업무 데이터 쓰기 시험은 `iris2_test_customer_*` 복제 DB에서 수행했다. 시험 서버와 DB를 제거했고, 실제 운영 DB의 Plugging 원장에는 시험 기록을 남기지 않았다. 운영 포트 4824를 가동하지 않았다.

## 권한·정합성

등록·취소에는 EXCHANGERS와 MAINTENANCE 편집 권한, 로그인, CSRF가 모두 필요하다. 등록자는 클라이언트 입력을 신뢰하지 않고 서버 계정으로 기록한다. 다른 설비·퇴역 bundle·가상 Map 위치·미래/설치일 이전 완료일·중복/변경된 상태를 거절한다. 같은 튜브의 동시 완료 등록은 한 요청만 반영한다. 동일 요청 재전송은 중복 등록하지 않는다.

취소 이벤트는 원본 완료를 참조하며 원장을 삭제하지 않는다. 실제 Plug 제거·튜브 교체를 취소로 처리하지 않는다. 기존 날짜 미상 PLUGGED는 임의 소급 입력하지 않는다. 완료 원장이 있는 튜브는 기존 일반 상태 변경으로 해제하지 못하도록 보호한다. 과거 기준일 계산에는 완료일 이전의 튜브 상태를 사용하며, 조회 중 ORM 객체를 수정하지 않는다.

## 다른 PC 적용

소스 업데이트만으로 DB 테이블·보정·서비스 재시작이 자동 수행되지는 않는다. 운영 서비스가 중지된 상태에서 해당 PC의 iris2 환경으로 다음 순서를 따른다.

```powershell
.\.venv\Scripts\python.exe migration/backup_mariadb.py
.\.venv\Scripts\python.exe tools/apply_customer_changes_20261124.py
.\.venv\Scripts\python.exe tools/apply_customer_changes_20261124.py --apply --backup backups/<해당-PC의-백업>.sql
.\.venv\Scripts\python.exe tools/verify_customer_changes_readonly.py
```

원본 PDF 해시·설비/검사 식별·예상 기존 값이 다르면 자동 보정은 중단된다. 별도 복제 DB 시험은 `test_customer_completion_mariadb.py`, 실제 화면 시험은 `tools/verify_customer_completion.py`로 실행한다. 시험 도구는 로컬 MariaDB 권한과 설치된 Chrome/Edge 및 Node 실행 환경을 사용한다. 일반 운영 기동 명령과 분리한다.
