# 잔여수명 대시보드와 정밀분석 기능 구현

구현일: 2026-10-28

## 사용자 화면 위치

| 기능 | 위치 | 사용 방법 |
|---|---|---|
| 잔여수명 구간 집계 | 대시보드 `/` 상단 | VCM1·VCM2의 구간별 숫자를 클릭하면 하단 설비 목록을 필터링하고 펼침 |
| 실제 다년도 두께 이력 | 정밀분석 `/analysis` → Map 또는 결과표에서 Tube 선택 → 하단 두께 이력 | 실제 검사일·최소두께와 원문 링크 표시. 설치 이전 이력은 조회 전용으로 구분 |
| 연도별 누적 Plugging 그래프 | 정밀분석 `/analysis` 하단 | 기준연도부터 25년 후까지 연말 누적 대상 수와 허용 한도선 표시. 펼침 표에서 당해·누적 수량 확인 |

대시보드 조회 예: `/?life_unit=VCM1&life_band=long#remaining-life-list`

## 분류와 데이터 기준

- `long`: 15년 초과
- `medium`: 5년 초과~15년 이하
- `short`: 5년 이하. 이미 도달한 경우 화면은 0년으로 표시
- `unknown`: 산정 불가·한도 미도달·총수량 미확인. 이를 장수명으로 분류하지 않음
- 대시보드는 기존 `_remaining_life_projection`을 사용하며 일반 20%, Critical 10%의 기본 허용 한도를 적용함
- 목록의 예측률은 등록 Tube 대비 계산 가능한 Tube 비율이며 전체 설계 Tube에 대한 검사 완료율과 다름
- 두께 이력은 실제 `iris_tube_result`와 `iris_inspection`을 조회. 동일일의 서로 다른 결과도 임의 평균·제거하지 않음
- 설치 이전 이력은 표시만 하고 기존 예측 제외 원칙을 유지
- 그래프는 실제 Tube별 예상일을 사용하며 표본 비율을 미검사 Tube로 확대하지 않음
- 이전 연도 도달분은 첫 표시연도의 누적 수량에 포함. 표시기간 이후 도달 건수는 별도 안내
- 허용 수량과 같으면 한도 이내, 초과하면 한도 도달. 기존 예측과 동일
- 부식속도 슬라이더 조작 시 그래프·연도별 표·수명 요약을 함께 갱신. 원래 측정값은 변경하지 않음
- 데이터가 없으면 빈 그래프를 정상수명으로 표시하지 않고 계산 가능한 데이터 없음 안내

## 변경 파일과 역할

| 파일 | 역할 |
|---|---|
| `application/life_dashboard.py` | 수명 경계값 분류, 공정별 집계, 선택 구간 필터 |
| `services.py` | `dashboard_remaining_life`, `precision_tube_histories`, 기존 화면 데이터에 연결 |
| `web/routes/dashboard.py` | `life_unit`, `life_band` 조회조건 전달 |
| `templates/dashboard.html` | 대시보드 상단 집계표, 구간 클릭 링크와 설비 목록 |
| `templates/precision_analysis.html` | 누적 그래프·연도별 표 영역, JS 캐시 버전 갱신 |
| `static/precision-analysis.js` | 실제 두께 이력 막대, 누적 SVG 그래프·표, 배율 연동 |
| `tests/test_life_dashboard.py` | 5·15년 경계, 산정 불가, 집계·목록 일치 시험 |
| `tests/test_annual_plugging.cjs` | 연말·연초 누적, 이전·이후 연도, 실제 이력·누락 두께 표시 시험 |

## 검증

- 공식 MariaDB 통합·계산 회귀시험: 97건 통과, 실패·오류·건너뜀 없음
- 화면/API/자원 검사: 139건 통과
- 비로그인 접근 차단: 46건 통과
- JavaScript 구문 및 기존 양방향 선택 시험 통과
- 신규 연도별 누적과 실제 두께 이력 JavaScript 시험 통과
- 실제 DB 집계: VCM1 81대, VCM2 131대, 합계 212대
- 다년도 이력 표본 조회: 열교환기 ID 67은 40건, ID 139는 50건
- 대시보드 실제 집계 조회 약 1.9초. 데이터 증가 시 성능 재평가 필요

브라우저 시각 배치·WebGL·실제 클릭을 이번에 별도로 검증한 것은 아니다. HTTP 렌더링·데이터와 JavaScript 기능시험으로 확인했다.

## 적용

DB 구조 변경이나 기존 검사값 수정은 없다. 실행 중인 웹 서버는 Python 코드 반영을 위해 재시작해야 한다. 변경된 정밀분석 JS에는 새 버전 쿼리를 적용했다.
