# Text-to-SQL 표현 확장

기존 원격 기간·검사 빈도 개선(b9ecd0b)을 작업 브랜치에 통합했다.

- 감육률: 두께 감소율, 감육 율, wall loss, 퍼센트/프로, 전각 숫자.
- Tube: 튜브, 전열관, tube/tubes.
- 요약: 검사 현황, 검사 결과 정리, summary.
- 순위: TOP N, 감육이 제일 큰/높은 Tube.
- 기간: 이번 달/이달, 지난달/전월, 이번 주/지난주(월요일 시작), 오늘/어제,
  현재 연도의 상반기/하반기, YYYY년 M월. 미래 날짜는 포함하지 않는다.

예: `지난달 두께 감소율 30퍼센트 이상 전열관`, `이번 달 검사 현황`,
`2025년 2월 감육이 제일 높은 튜브 5개`.

언어 정규화는 모델 입력과 서버 의미 검증 양쪽에 적용한다. 숫자 바인딩,
SELECT 문법 제한, 서버가 확정한 VCM1/VCM2 설비·검사 회차 및 읽기 계정 검증을 유지한다.
일반 조회는 선택한 설비 범위에서 수행되며, 질문 속 설비명이 선택 범위를 변경하지 않는다.
검사 건수와 Tube 개수는 다른 지표다. 이력 비교·잔여수명·검사계획과 대화 맥락
승계는 이번 표현 확장 대상이 아니다. 실제 모델 응답 정확도는 로컬 모델을 이용한
현장 질문 평가가 별도로 필요하다.

## 2026-11-15 통합

- 언어 확장 커밋 8b48396을 전체 검증 커밋 e20871c 기반으로 병합했다. API 510 승인 잠금·계산 경계값·백업 보관 정책·대시보드 최하단 배치를 유지했다.
- `올해 3월`과 `작년 3월`을 해당 월의 시작일~말일로 해석한다. 연도 없는 `3월`이나 지원하지 않는 일자 표현은 연도 전체로 확대하지 않고 거절한다.
- 전열관 동의어 및 전각 TOP 개수는 검사 횟수 이력 경로에도 적용한다. 일반 질문도 서버에서 표현을 정규화한 뒤 기간과 모델 입력을 확정한다.
- 퍼센트 단위 변환은 숫자 뒤의 단위로 한정하여 `프로젝트`·`프로그램` 같은 일반 단어를 훼손하지 않는다.
- 기존 SQL 허용 문법과 권한 범위는 변경하지 않는다. 스키마·계정·운영 서버 전환은 별도이다.
- 검증: 전체 회귀 테스트 418건 통과(기존 미전환 SQLite 테스트 11개 모듈은 별도), Text-to-SQL JavaScript 문법·상세 링크 테스트 통과. 실제 로컬 LLM에서 `2025년 11월 검사 현황`을 생성·실행하여 월 범위와 결과 10건이 독립 SQL과 일치함을 확인했다. 원시 로그와 테스트 DB는 Git에 포함하지 않는다.
