# Text-to-SQL 표현 확장

기존 원격 기간·검사 빈도 개선(b9ecd0b)을 작업 브랜치에 통합했다.

- 감육률: 두께 감소율, 감육 율, wall loss, 퍼센트/프로, 전각 숫자.
- Tube: 튜브, 전열관, tube/tubes.
- 요약: 검사 현황, 검사 결과 정리, summary.
- 순위: TOP N, 감육이 제일 큰/높은 Tube.
- 기간: 이번 달/이달, 지난달/전월, 이번 주/지난주(월요일 시작), 오늘/어제,
  현재 연도의 상반기/하반기, YYYY년 M월. 미래 날짜는 포함하지 않는다.

예: `지난달 두께 감소율 30퍼센트 이상 전열관`, `이번 달 검사 현황`,
`2025년 2월 감육이 제일 높은 튜브 5개`.

언어 정규화는 모델 입력과 서버 의미 검증 양쪽에 적용한다. 숫자 바인딩,
SELECT 문법 제한, 서버가 확정한 VCM1/VCM2 설비·검사 회차 및 읽기 계정 검증을 유지한다.
일반 조회는 선택한 설비 범위에서 수행되며, 질문 속 설비명이 선택 범위를 변경하지 않는다.
검사 건수와 Tube 개수는 다른 지표다. 이력 비교·잔여수명·검사계획과 대화 맥락
승계는 이번 표현 확장 대상이 아니다. 실제 모델 응답 정확도는 로컬 모델을 이용한
현장 질문 평가가 별도로 필요하다.
