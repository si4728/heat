# 지능형 열교환기 관리시스템 주간업무 보고서

- 프로젝트: IRIS2 MariaDB 기반 열교환기 관리시스템
- 보고 기간: 2026년 10월 19일 ~ 10월 26일
- 작성 기준일: 2026년 10월 26일
- 개발·검증 범위: VCM1·VCM2

## 1 주요 추진 결과

등록 설비 기준의 데이터 집계와 정밀 분석 화면 개선 내용을 정리하고, MariaDB 기반 업무 화면과 주요 기능을 재점검했다. 10월 26일 실행한 회귀·통합 테스트 90건, 화면·API·정적 자원 점검 139건, 비로그인 접근 차단 점검 46건은 모두 통과했다. 프로젝트 소스와 인증정보를 제거한 DB 덤프를 GitHub에 등록해 소스 관리 및 복원 자료를 확보했다.

브라우저에서의 전체 화면 조작, 3D 그래픽·QR 카메라, 공개용 DB 덤프의 신규 환경 복원 시험은 후속 검증 대상으로 남아 있다.

## 3 화면 및 기능 점검 결과

| 점검 항목 | 실적 | 판정 |
|---|---:|---|
| MariaDB 통합·계산 회귀 테스트 | 90건 | 전부 통과, 실패·오류·건너뜀 0건 |
| 인증된 화면·API·PDF·정적 자원·입력값 점검 | 139건 | 전부 통과 |
| 비로그인 접근 차단 | 46건 | 전부 통과 |
| 전체 화면 템플릿 컴파일 | 44개 | 정상 |
| PDF/OCR 지정 권한 화면 | 1개 화면 | 정상 접근 확인 |
| PDF/OCR 원본 근거 PDF 접근 | 11개 | 정상 응답 |
| JavaScript 동작 테스트 | 2종 | Map·표 선택 연동, 조직 선택 통과 |
| 애플리케이션 JavaScript 문법 검사 | 16개 파일 | 정상 |

대시보드, 설비 목록·상세·수정, 조직·공장·공정 기준정보, 검사이력·계획, Tube 관리·Map, 정밀 분석, 잔여수명·API 510, 정비·작업지시, 가져오기·품질 이슈, ML 검토·Hotspot·패턴, AI 조회·보고서 검토, 사용자·권한, DB 모니터·백업·화면 설정 관련 경로를 점검했다. VCM1·VCM2의 대표 설비를 이용한 공정별 조회도 수행했다.

운영 DB에 작업지시서가 없어 해당 상세 화면과 업무 흐름은 격리된 테스트 DB에서 확인했다. 실제 자료를 사용하는 화면 점검은 GET 요청 중심으로 수행했으며, 생성·수정 흐름은 공식 통합 테스트의 격리 스키마에서 검증했다.

위 결과는 서버 응답·템플릿·자동화 검증 결과다. 모든 화면의 브라우저 클릭과 시각적 배치까지 검증 완료한 것으로 해석하지 않는다.

## 4 데이터 현황

| 항목 | 수량 | 기준 |
|---|---:|---|

| 검사이력 | 435건 | 10월 26일 재조회 |
| Tube 검사결과 | 6,084건 | 10월 26일 재조회 |
| 현재 사양의 Tube 수량 합계 | 69,105개 | 10월 23일 집계, 수량 확인 설비 249대 기준 |
| Tube 수량 미등록 설비 | 651대 | 10월 23일 원본 대조, 이 중 VCM1·VCM2 81대 |

전체 등록 현황은 보존된 기존 자료를 포함한 참고 집계이며, 신규 개발·현장 검증 범위를 확대한 것은 아니다. 수량 미등록 설비는 원본 근거 없이 0이나 추정값으로 채우지 않았다. 69,105개는 수량 확인 설비의 합계이므로 전체 설비의 확정 물리 Tube 총량으로 사용하지 않는다. 정보 입력 완료 여부와 실측값의 정확성·공학적 적합성은 별도로 검토한다.

## 5 소스 및 DB 관리

- 저장소: https://github.com/si4728/heat
- 등록 브랜치 및 커밋: main / 3ab43b44e6707b818186779fc1510eec1a198c76
- 등록 내용: 프로젝트 파일 395개, 최근 검증 결과, DB 덤프, 복원 안내 및 체크섬.
- DB 포함 범위: iris2, iris2_llm, iris2_ml, iris2_pdf의 테이블·데이터·트리거·루틴.
- 덤프 크기: 압축 전 약 46.36 MB, 압축 후 약 3.09 MB. 압축·해제 일치 검사 완료.
- 인증정보 처리: DB 접속 비밀번호·API 키·세션 비밀키 제외. 공개용 덤프의 애플리케이션 로그인 비밀번호 해시 3개를 무효화하고 복원 후 재설정 안내.
- 원본 PDF·source_json은 사용자 결정에 따라 공개 저장소에서 제외. 로컬 자료는 보존.
- 로컬 DB 데이터와 로그인 비밀번호는 변경하지 않았으며, 공개용 덤프는 별도로 생성.

테스트 스키마와 MariaDB 시스템 계정은 덤프에 포함하지 않았다. 공개용 덤프를 신규 서버에 복원하는 시험은 아직 수행하지 않았으며, 원본 근거 파일을 별도로 배치해야 복원 환경에서 관련 PDF 링크와 파일 기반 기능을 사용할 수 있다.
