# 지능형열교환시스템 금주 추진 결과

- 기준일: 2026-09-14
- 대상 기간: 2026-09-14 ~ 2026-09-18

## 1. 점검요청·승인 데이터

- 검사실적 기반 완료 검사계획 및 승인 데이터 435건이 생성된 상태를 확인했다.
- 재실행 Dry-run 결과 신규 생성 대상 0건, 중복 연결 0건, 비정상 승인기한 0건, 외래키 위반 0건이었다.
- DB 무결성 검사 결과는 `ok`이며, 동일 작업을 재실행해도 중복 생성되지 않는다.

## 2. Database Backup/Restore

- 운영 DB 수동 백업을 실행하고 파일 크기, SHA-256, SQLite 무결성 및 외래키를 검증했다.
- 관리자 화면에서 보관 백업을 선택하고 복구 사유를 입력해 Restore할 수 있도록 기능을 추가했다.
- Restore 전 현재 DB를 자동 백업하고, 대상 파일 사전 검증, 복구 후 무결성·외래키 검증, 실패 시 자동 Rollback, 감사 로그 기록을 구현했다.
- 정상 백업 복구와 손상 파일 차단 단위시험 3건이 통과했다.

## 3. 모바일 최적화 검증

- Edge CDP 390×844 모바일 터치 에뮬레이션으로 Tube Map을 재검증했다.
- 화면 overflow, 툴바 배치, 2D Tube 선택, 3D 단일 Tube 분리, 회전·확대·이동, JavaScript 오류 여부 등 10개 항목이 모두 통과했다.
- 실물 Android/iOS 단말이 연결되지 않아 실제 OS·브라우저 조합 시험은 미완료 상태다.

## 4. ML 활용방안 검토

| 활용 후보 | 판정 | 적용 조건 |
|---|---|---|
| 이상치 우선순위 | 우선 적용 | 읽기 전용 검토지원 유지, 전문가 Precision 기준 확정 |
| 공간 Hotspot | 우선 적용 | 승인 Layout만 사용, 전문가 상위 후보 검토 |
| 데이터 품질 탐지 | 우선 적용 | 원본 근거 연결 및 오탐 검토 Workflow 유지 |
| 유사 열화 패턴 | 조건부 적용 | 전문가 라벨 확보 후 그룹 의미 검증 |
| 감육 추세예측 | 보류 | 80% 예측구간 포함률 Gate 충족 후 재검토 |
| 검사·정비 우선순위 | 후속 검토 | 자동 승인 금지, 엔지니어 최종판정 유지 |

- ML 실행환경은 Python 3.13과 NumPy, SciPy, scikit-learn 설치 상태가 정상이다.
- ML 솔루션 도입 방안 확정 후 H/W 사양을 검토하여 10월 초까지 제시하고, 확정된 H/W는 당사에서 직접 설치·구성하여 납품하는 방식을 제안한다.

## 5. 잔여 항목

- 현장 운영조건에서 Backup 스케줄 누락 회차 보완 실행과 Restore UAT 수행
