## 3. 잔여수명 구간별 현황 표 정렬

### 원본 요구사항

‘잔여수명 구간별 열교환기 현황’의 열 너비를 동일하게 맞춰 주세요.
- 제목 행부터 VCM1·VCM2·합계 행까지 세로 경계가 정확히 일치하도록 정렬
- 각 열의 제목과 수량은 가운데 정렬
- 긴 제목은 일정한 기준으로 줄바꿈하고 제목 행 높이를 통일
- 합계 행은 배경색 또는 굵은 글씨로 구분
‘산정 불가’와 ‘한도 미도달’은 의미가 다르므로, 가능하면 별도 항목으로 구분해 주세요. 한도 미도달을 산정 불가나 안전 판정으로 오해하지 않도록 설명도 부탁드립니다.

### 최종 반영 내용 및 확인 결과

**반영 상태: 확인 완료**

- 공정·15년 초과·5년 초과 15년 이하·5년 이하·산정 불가·한도 미도달·합계의 7개 열을 동일 비율로 구성했습니다.
- 제목·VCM1·VCM2·합계 행의 세로 경계와 가운데 정렬을 확인했습니다. 확인한 데스크톱 화면의 제목 셀 높이는 모두 64px입니다.
- 긴 제목은 두 줄로 표시하며 합계 행은 연한 주황색 배경과 굵은 글씨로 구분합니다.
- **산정 불가**: 예측에 필요한 데이터가 부족한 상태입니다.
- **한도 미도달**: 계산 가능한 Tube의 가용 예측에서 허용 수량 초과 시점이 나오지 않은 상태입니다. 무한 수명·안전 판정·장수명을 의미하지 않습니다.
- 미예측 Tube 제외 및 부분 검사 결과에 따른 예측이라는 설명을 본문과 도움말에 표시했습니다.
- 확인 시점 VCM1·VCM2 합계는 212대입니다. 15년 초과 11대, 중간·단기 구간 각 0대, 산정 불가 109대, 한도 미도달 92대입니다.
- 좁은 화면에서는 표를 가로 스크롤하여 확인합니다.

## 4. 정밀 분석에서도 왼쪽 시스템 메뉴 유지

### 원본 요구사항

정밀 분석에 들어가도 대시보드·열교환기 관리·검사 관리·정비 관리·기본 설정 메뉴가 동일하게 보이도록 해 주세요.

정밀 분석 안의 ‘열교환기 선택 목록’은 공통 시스템 메뉴와 구분하여 배치해 주세요. 다른 화면으로 이동하기 위해 브라우저 뒤로가기를 사용할 필요가 없도록 하고, 현재 메뉴와 선택 설비도 명확히 표시해 주세요.

화면이 좁아지는 경우에는 메뉴 접기 기능을 제공하되, 본문 위에 메뉴가 길게 나열되지 않도록 해 주세요.

### 최종 반영 내용 및 확인 결과

**반영 상태: 확인 완료 — 좁은 화면의 추가 검증 필요**

- 정밀 분석에서도 대시보드·열교환기 관리·검사 관리·정비 관리·기본 설정 공통 메뉴가 유지됩니다.
- **분석 대상 · 열교환기 선택 목록**을 공통 메뉴와 별도 배치했습니다.
- 현재 메뉴와 선택 설비를 표시하고 선택 설비를 목록에서 강조합니다.
- 공통 메뉴로 정비 관리에 실제 이동해 뒤로가기 없이 화면 전환 가능한 것을 확인했습니다.
- 좁은 화면에서 공통 메뉴와 설비 목록이 접히며 공통 메뉴는 왼쪽 서랍으로 펼쳐집니다.
- 검증 한계: 768px 요청 시험의 실제 적용 너비는 1024px였습니다. 768px 이하·390px에서의 실제 배치는 추가 확인이 필요합니다.
- 시험 후 화면 크기와 메뉴 상태를 복원했습니다.

## 5. QR 관련 메뉴와 버튼 우선 숨김

### 원본 요구사항

QR 기능은 당분간 사용하지 않을 예정이므로 전체 화면에서 관련 진입 항목을 숨겨 주세요.
- 운영 현황의 ‘QR 검색’, ‘QR-code 읽기’
- 열교환기 상세의 ‘QR 간편조회’
- 그 외 QR 조회·스캔·생성 관련 메뉴와 버튼
이번 요청은 사용자 화면에서의 노출 제외이며, 향후 다시 사용할 수 있도록 처리해 주세요.

### 최종 반영 내용 및 확인 결과

**최종 요구사항 변경: 관리자에게만 표시, 일반 사용자에게는 숨김**

원본의 전체 사용자 숨김 요청은 2026-11-10 사용자 지시에 따라 위 기준으로 변경했습니다.

**반영 상태: 관리자 실제 화면 확인 및 권한별 템플릿 검증 완료**

- 운영 현황 QR 검색·QR-code 읽기와 상세의 QR 간편조회는 관리자에게 표시합니다.
- 일반 사용자에게는 QR 진입 버튼·스캔 창·스캐너 스크립트를 제외합니다.
- 관리자도 열교환기 조회 권한이 있어야 QR 진입 항목이 표시됩니다.
- QR 기능 코드를 보존하고 **QR_UI_ENABLED** 설정으로 전체 노출을 제어합니다.
- 서버 재시작 후에도 관리자 전용 노출 기준을 유지하도록 표시 설정을 반영했습니다.
- 검증: 관리자 실제 화면 및 관리자/일반 사용자·조회 권한 유무를 적용한 실제 템플릿 렌더링 테스트.
- 한계: 일반 사용자 계정의 직접 로그인 검증은 하지 않았습니다. UI 노출 검증이며 QR 주소 직접 접근의 권한 검증과는 구분합니다.

## 6. 실제 Plugging과 예측 대상 표시 구분

### 원본 요구사항

실제 Plugging 완료 수량과 감육 기준 도달·예측 대상 수량을 명확히 구분해 주세요.

예를 들어 E-131D는 튜브 관리에서 실제 Plugged가 0개인데, 상세·QR 화면에는 ‘현재 Plugging’이 5개로 표시됩니다. 화면마다 집계 의미를 확인하여 다음과 같이 명칭을 통일해 주세요.
- 실제 Plugging 완료 수량
- Plugging 기준 도달 대상 수량
- 향후 Plugging 예상 수량
‘사용 중’, ‘미검사’, ‘등록되지 않은 튜브’도 서로 다른 상태임을 알 수 있도록 표시해 주세요.

### 최종 반영 내용 및 확인 결과

**반영 상태: 개선 적용 및 실제 화면 확인 완료**

### 수량과 상태 구분

- 실제 완료는 등록 PLUGGED 상태, 기준 도달은 실제 완료를 제외한 최근 검사 감육률 기준 도달 Tube, 향후 예상은 실제 완료·현재 기준 도달 대상을 제외한 계산 기준일 이후 예측 가능 Tube로 구분합니다.
- 사용 중은 개별 등록된 IN_SERVICE 상태로, 검사 여부와 별개입니다.
- 미검사는 등록 Tube 중 현재 설치기간 검사결과가 없는 상태입니다.
- 미등록 Tube는 운전 상태·검사 여부 미확인으로, 사용 중·미검사 수량에 포함하지 않습니다.

### 추가 개선 반영

1. **Map 미등록 위치 분리**: UNREGISTERED 분류와 상태 미확인을 적용했습니다. 회색 점선은 미등록 위치, 흰색은 등록 튜브의 미검사·감육률 미등록 상태입니다. 범례·툴팁·표시 위치 합계 및 Map 집계에서 별도 구분합니다. PDF 표시 위치가 물리 Tube 등록·좌표 승인을 뜻하지 않음을 설명합니다.
2. **예측률 분모 명시**: 전체 사양 대비와 개별 등록 대비 비율을 각각 표시합니다. 미등록 및 등록 중 예측 제외 수량을 구분하며, 평가 제외를 안전 판정으로 해석하지 않도록 안내합니다. 정밀 분석·상세·QR·독립 예측·보고서에서 확인했습니다.
3. **잔여수명 문구 통일**: 한도 미도달 상태의 기존 ‘-년’을 **가용 데이터에서 한도 미도달**로 통일했습니다. 이미 기준을 넘은 Tube는 **최근 검사에서 기준 도달 확인 — 실제 도달일 미상**으로 표시합니다. 최근 검사일과 계산 기준일을 구분합니다.
4. 상세·QR에서 전체 설치 수량으로 오해할 수 있는 ‘물리 튜브’를 **개별 등록 튜브**로 변경했습니다.
