## 현재 데이터에서 달라진 수량과 미산정 원인

현재 로컬 MariaDB 212대, 계산 기준일 2026-11-17을 대조했다. 기존 한도 미도달은 원문과 같은 **92대**다. 그중 표본 추정이 선택한 최신 회차에 원시 튜브 결과가 10본 이상인 설비는 **78대**이며, 현재 코드에서 20% 도달 예측 또는 추정상 도달 결과가 있는 설비는 **71대**다. 나머지 **7대**는 아래 원인으로 추정이 막힌다. 따라서 원문의 78대는 표본 수에 따른 후보 수량으로 재현되며, 78대 전부에 현재 사용 가능한 도달 연도가 있다는 의미로는 재현되지 않는다.

아래 7대의 집계 범위는 **한도 미도달 92대 중 원시 표본 10본 이상인 78대**다. 원시 표본은 해당 회차의 서로 다른 `tube_id` 수이며, 승인·유효성 필터 이후 표본 수와 구분한다. 여러 번들의 전체 표본을 합산한 수량은 아니다.

유효 표본 10본 이상만 세면 이 78대 중 77대다. E-105가 승인 상태 필터에서 제외되기 때문이다. 반면 전체 212대에서 유효 표본 10본 이상이면서 미산정인 설비는 8대로, 위 6대(E-105 제외)에 E-122A·E-341이 추가된다. E-122A·E-341은 기존 상태가 `INSUFFICIENT_DATA`이므로 한도 미도달 92대에 속하지 않는다. 앞선 검토의 “미산정 8대”와 원문의 “7대”는 이처럼 집계 범위와 표본 정의가 달랐다.

AE-502A/B/D는 DB상 MAIN·1·2 번들이 모두 활성이고 각 번들에 전체 사양과 같은 384본이 기록되어 있다. 서로 다른 `bundle_id`라는 사실만으로 독립적인 물리 번들이라고 확정할 수 없다. 384본을 중복 합산하거나 같은 튜브를 두 번 세지 않도록 원본의 실제 번들·pass·검사 구분과 ID 연결을 먼저 정리한다. 식별이 모호한 동안 추정 차단을 해제하지 않는다.

추가 원인은 다음과 같다.

- **E-105:** 최신 결과의 `result_status`는 VALID지만 `quality_status`는 `USER_APPROVED_211MM_BASIS`다. 현 필터가 NULL/VALID만 허용해 20본 모두 표본과 감육속도 계산에서 빠진다. 승인 사유와 기존 정정 이력을 확인하고 이 상태를 명시적 허용 목록으로 일관되게 처리한다. 모든 임의 상태를 유효 처리하지 않는다.
- **E-341:** 최근 10본의 감육률이 모두 0으로 통계 분산이 없다. 과거 양수 측정과 현재 0의 관계는 교체·측정조건·보고서 근거로 구분한다. 계산 실패를 설치일 오류로 분류하는 코드도 수정한다.
- **E-13:** 최근 표본 5본, 감육률은 모두 0이다. 표본 부족과 양의 감육속도 부재를 각각 설명한다. 검사 이력이 있다는 이유만으로 수명을 산정하지 않는다.

## 공통 계산 기준

### 검사 적격성과 수량

검사 범위, 검사 결과 상태, 승인 품질 상태, 대체 검사 여부, 현재 설치기간을 공통 함수로 판정한다. 원본 이력의 표시 가능 여부와 감육속도·통계 추정 입력 가능 여부는 각각 반환한다. `ALL` 이외의 코드를 전부 부분 축방향 검사로 단정하지 않고, Tube Sheet 위치 구분과 튜브 길이 방향 검사 범위를 원본과 대조한다. E-111 TOPSOUTH는 원문 요청과 근거를 연결해 계산 제외 대상으로 등록한다.

제외한 부분 검사값은 두께 이력에서 계속 조회하되 제외 배지와 사유를 제공한다. 단기 속도는 직전의 적격 검사, 회귀 속도는 적격 검사만 사용한다. 적격 최신 검사 자체가 없으면 다른 범위 측정을 전체 검사처럼 사용하지 않고 산정 불가 사유를 반환한다.

U-tube 3대의 목표 물리 수량은 E-123 9본, E-550 46본, E-401 80본이다. 공장·공정·열교환기·현재 사양 Revision으로 대상을 고정하고 사전값이 기대값과 일치할 때만 정정하도록 만든다. 직관 수/끝단 수와 물리 튜브 수를 구분하며, U-tube 전체를 일괄 2로 나누지 않는다. 원본 검사 수량과 과거 사양은 보존하고 변경 근거·전후값·되돌릴 기준을 기록한다. 현재 번들의 기대 수량도 각각 18·92·160본이므로 사양 수량만 바꾸고 번들 값은 남겨두지 않도록 정합성을 확인한다. 수정한 물리 수량은 대시보드 전체 튜브 수, 표본 추정, 허용 Plugging 수량, 보고서에 동일하게 적용한다. Map은 끝단 표시와 물리 튜브의 대응 관계를 확인하고 점을 단순히 절반 삭제하지 않는다.

### 대표 잔여수명과 표시

설비 대표값은 표본 10본 이상이며 회귀·모수·설치일·검사 집단 조건이 유효한 경우 표본 기반 **Plugging 20% 도달 예상일**을 우선한다. 조건이 부족하면 기존 실측 튜브 수량 한도 결과로 돌아가며, 어느 결과를 사용했는지와 추정 불가 사유를 함께 전달한다. 20% 경계 도달과 기존 허용 수량의 최초 초과는 서로 다른 계산이므로 원시 결과를 덮어쓰지 않는다.

`FORECAST`는 예상일까지의 남은 기간을 공통 계산 기준일에서 산출한다. `ESTIMATED_REACHED`는 잔여기간 0과 “검사일 기준 추정상 도달”로 표시하며 정확한 과거 도달 연도를 만들지 않는다. 실측 도달·통계 추정상 도달·실제 Plugging 완료를 구분한다. 통계 추정으로 API 510 승인값이나 실제 작업 기록을 변경하지 않는다.

여기서 “Plugging 20% 도달”의 20%는 전체 튜브 중 기준 도달 비율이다. 개별 튜브의 Plugging 감육률 기준(현재 기본 40%)과 구분하고 설비별 승인 설정을 표시한다. Summary를 추가하면서 기존 검사 권고의 실측/추정 기준이나 저장·승인 절차를 자동 변경하지 않는다.

30년 표시 제한은 기존 대시보드와 같은 달력 기준 경계를 공유한다. 30년을 초과하는 경우 “30년 이상”으로 표시하되 원시 예상일은 정렬·계산·근거 조회용으로 보존한다. 정확히 30년인 경우, 윤년, 이미 도달, 산정 불가를 별도 시험한다.

### 설비 Summary

최초 진입 시 튜브를 자동 선택하지 않고 Map 오른쪽에 다음 항목을 표시한다. 명시된 `tube_id`가 있으면 해당 설비 소속인지 검증하고 기존 튜브 상세를 연다.

- 예상 잔여수명과 Plugging 20% 도달 연도, 통계/실측 기준 표시.
- 최초 Plugging 기준 도달 예상일. 추정과 실측 최초 도달을 구분한다.
- 측정/추정 최대 감육률, 감육률 상위 튜브 5개.
- 차기 검사 권고일과 계산 기준. 기존 권고 함수와 같은 기준을 사용하고 그림의 날짜를 고정하지 않는다.
- 같은 검사 집단의 유효 검사 표본 수 / 물리 전체 수량, 검사일과 제외 사유.

잔여수명과 최초 도달을 가장 크게 표시하고 5년 이하·이미 도달은 색과 텍스트를 함께 사용한다. 튜브 선택 시 두께 이력·감육속도로 전환하며 “설비 요약”으로 돌아오는 조작을 제공한다. 설비 변경 시 이전 튜브 선택과 요약 데이터를 초기화한다. 화면 예시의 E-104B 수치는 검증 사례로 사용하되 코드에 고정하지 않는다. 감육속도 배율 시뮬레이션은 원시 통계 추정과 분리해 표시한다.
