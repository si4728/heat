현재 개발된 시스템을 확인하고, 아래와 같이 화면 수정 및 사용성 개선을 요청드립니다.

1. 시스템 명칭 변경

왼쪽 상단의 ‘IRIS2’와 기존 시스템명은 아래와 같이 변경해 주세요.
- 상단: i-HMS
- 하단: 지능형 열교환기 관리 시스템
기존 영문 부제는 제거하고, 로그인 화면과 각 화면의 시스템 명칭도 동일하게 맞춰 주세요.

2. 운영 현황의 미등록 관련 항목 제거

운영 현황에서는 검사·수명·설비 현황을 중심으로 볼 수 있도록 다음 항목을 제외해 주세요.
- ‘Tube 수량 미등록 열교환기’ 영역과 미등록 설비 목록
- ‘Tube 미등록 열교환기’ 집계 카드
- 위 항목에 연결된 미등록 현황 안내 문구
해당 정보는 필요한 경우 ‘기본 설정 → 데이터 입력 현황’에서 확인하도록 하고, 운영 현황에서 제외한 자리와 여백도 정리해 주세요.

3. 잔여수명 구간별 현황 표 정렬

‘잔여수명 구간별 열교환기 현황’의 열 너비를 동일하게 맞춰 주세요.
- 제목 행부터 VCM1·VCM2·합계 행까지 세로 경계가 정확히 일치하도록 정렬
- 각 열의 제목과 수량은 가운데 정렬
- 긴 제목은 일정한 기준으로 줄바꿈하고 제목 행 높이를 통일
- 합계 행은 배경색 또는 굵은 글씨로 구분
‘산정 불가’와 ‘한도 미도달’은 의미가 다르므로, 가능하면 별도 항목으로 구분해 주세요. 한도 미도달을 산정 불가나 안전 판정으로 오해하지 않도록 설명도 부탁드립니다.

4. 정밀 분석에서도 왼쪽 시스템 메뉴 유지

정밀 분석에 들어가도 대시보드·열교환기 관리·검사 관리·정비 관리·기본 설정 메뉴가 동일하게 보이도록 해 주세요.

정밀 분석 안의 ‘열교환기 선택 목록’은 공통 시스템 메뉴와 구분하여 배치해 주세요. 다른 화면으로 이동하기 위해 브라우저 뒤로가기를 사용할 필요가 없도록 하고, 현재 메뉴와 선택 설비도 명확히 표시해 주세요.

화면이 좁아지는 경우에는 메뉴 접기 기능을 제공하되, 본문 위에 메뉴가 길게 나열되지 않도록 해 주세요.

5. QR 관련 메뉴와 버튼 우선 숨김

QR 기능은 당분간 사용하지 않을 예정이므로 전체 화면에서 관련 진입 항목을 숨겨 주세요.
- 운영 현황의 ‘QR 검색’, ‘QR-code 읽기’
- 열교환기 상세의 ‘QR 간편조회’
- 그 외 QR 조회·스캔·생성 관련 메뉴와 버튼
이번 요청은 사용자 화면에서의 노출 제외이며, 향후 다시 사용할 수 있도록 처리해 주세요.

6. 실제 Plugging과 예측 대상 표시 구분

실제 Plugging 완료 수량과 감육 기준 도달·예측 대상 수량을 명확히 구분해 주세요.

예를 들어 E-131D는 튜브 관리에서 실제 Plugged가 0개인데, 상세·QR 화면에는 ‘현재 Plugging’이 5개로 표시됩니다. 화면마다 집계 의미를 확인하여 다음과 같이 명칭을 통일해 주세요.
- 실제 Plugging 완료 수량
- Plugging 기준 도달 대상 수량
- 향후 Plugging 예상 수량
‘사용 중’, ‘미검사’, ‘등록되지 않은 튜브’도 서로 다른 상태임을 알 수 있도록 표시해 주세요.
