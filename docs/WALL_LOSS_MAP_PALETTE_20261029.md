# Tube Map 감육률 색상 통일

- 적용: 정밀분석 Map, 2D/3D 배열도, 단일 튜브·내외면 전개도·국부 결함 패치, 범례·툴팁·선택 구간, 기본설정 Wall Loss 색상 기준.
- 공통 구현: `static/wall-loss-palette.js`. 40% 이상을 같은 색으로 포화시키던 보간을 제거했다.
- Nominal 0%, 01~10%, 11~20%, …, 81~90%, 91~99%, 100% 이상을 독립 색상으로 표시한다. 미검사/값 없음은 흰색, Plugged는 검정색이며 운전 상태가 우선이다.
- 소수는 정수 반올림하여 표시 구간만 정한다. 측정값·위험 판정 임계값·Plugging 40%·잔여수명 계산은 변경하지 않는다.
- 기본설정은 원본 보고서 방식의 고정 구간 팔레트를 조회하도록 전환했다. 이전 3단계 사용자 색상은 DB에 보존되며 Map에 적용하지 않는다.
- 원본 PDF 파일은 변경하지 않는다. 인쇄 보고서는 별도 색상 Map이 없는 표 기반 화면으로 유지한다.
- E-241B-1: 21~30%=3, 31~40%=1, 41~50%=3, 51~60%=2, 61~70%=1, 값 없는 위치=128. 원본 138개 위치와 분포 일치.
- 검증: 기존 Python 121개 통과, Node 구간 경계값·누락값·Plugged 우선·원본 5색 분포 테스트 통과, 브라우저 정밀분석/2D/3D 렌더링 확인.
