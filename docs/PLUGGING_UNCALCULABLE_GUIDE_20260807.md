# Plugging 예상 산정 불가 판단 기준 및 현재 의견

- 작성일: 2026-08-07
- 적용 화면: 교환기 상세 → 결함 목록 → Plugging 예상
- 조회 기준일: 시스템 현재일 또는 `hx_configuration.conf`의 고정 기준일

## 1. 계산식

튜브별 Plugging 도달 연도는 다음 식으로 계산한다.

`최근 검사일 + (공칭두께 × 설정된 Plugging 감육비율 − 검사 시 감육량) ÷ 부식속도`

계산에는 최근 검사일, 공칭두께, 검사 시 감육량, 양수의 부식속도가 필요하다. 감육량이 설정된 Plugging 기준 이상이거나 튜브 상태가 `PLUGGED`이면 이미 Plugging된 것으로 처리한다.

## 2. 산정 불가가 되는 경우

1. 해당 튜브의 검사 결과가 없는 경우
2. 공칭두께가 없고 검사 결과의 감육량·감육률 또는 최소잔존두께·감육률로도 역산할 수 없는 경우
3. 현재 감육량을 구할 수 없는 경우
4. 서로 다른 검사일의 유효한 두께 결과가 2개 이상 없어 부식속도를 계산할 수 없는 경우
5. 계산된 부식속도가 없거나 0 이하인 경우

부식속도가 없거나 0 이하인 상태에서 감육률이 40% 미만이면 미래 도달 연도를 임의로 예측하지 않는다.

## 3. E-331D 확인 결과

- 생산공장/생산라인: P1 / PE
- 검사일: 2020-10-23 한 번
- 관리 튜브: 5개
- 감육률 범위: 15.17%~36.02%
- 공칭두께: 검사 결과로 약 2.11 mm 역산 가능
- 부식속도 평가: 0건
- 예측 가능 튜브: 0개
- 산정 불가 튜브: 5개
- 시스템 제외 사유: `NO_POSITIVE_CORROSION_RATE`

가장 높은 감육률을 가진 Tube 6-3은 공칭두께 약 2.11 mm, 현재 감육량 0.76 mm, 40% Plugging 기준 감육량 약 0.844 mm이다. 남은 감육량은 약 0.084 mm이지만 부식속도가 없어 소진 시점을 계산할 수 없다.

## 4. 현재 의견

E-331D의 산정 불가는 계산 오류가 아니라 시계열 검사자료 부족에 따른 정상적인 보수적 처리다. 근거 없는 임의 부식속도를 적용하면 잔여수명을 과대 또는 과소평가할 수 있으므로 현재처럼 산정 불가로 표시하는 것이 적절하다.

다만 E-331D의 튜브 마스터 상태가 `PARTIAL`이고 5개 결함 튜브만 관리되고 있으므로, 설비 전체 잔여수명 판단에는 전체 튜브 수와 전체 튜브 마스터의 보완도 필요하다.

## 5. 산정 가능 상태로 전환하기 위한 조건

1. 동일한 물리 튜브 ID가 유지된 후속 IRIS 검사 결과를 적재한다.
2. 서로 다른 검사일의 최소잔존두께를 비교할 수 있어야 한다.
3. 계산된 부식속도가 0보다 커야 한다.
4. 공칭두께와 전체 튜브 수를 교환기 기준정보에 등록한다.
5. 데이터 매핑과 검사 품질을 확인한 후 감육 평가를 다시 생성한다.

부식속도를 별도로 수동 입력하는 기능을 도입할 경우에는 입력 근거, 적용기간, 승인자와 변경 이력을 함께 관리해야 한다.
