# 2026-11-10 화면 및 사용성 개선

시스템 표시 명칭을 i-HMS / 지능형 열교환기 관리 시스템으로 통일했다. 내부 패키지·DB·세션 이름은 유지한다.

운영 현황의 미등록 설비 패널·카드·안내를 제거했다. 미등록 수량과 목록 검색은 관리자 전용 데이터 입력 현황에 배치했다.
잔여수명 표는 7개 동일 너비 열로 정렬했다. 산정 불가와 한도 미도달을 분리하고, 후자는 가용 예측 데이터에서 한도 초과 시점을 얻지 못한 상태이며 안전 판정이 아님을 설명한다.

정밀 분석에서도 공통 메뉴와 현재 메뉴를 표시한다. 열교환기 선택은 별도 접기 영역이며 선택 설비를 표시한다. 1100px 이하에서는 공통 메뉴를 기본 접고 필요 시 고정 레이어로 열어 본문 위 메뉴 나열을 방지한다.

QR UI는 기본 false인 QR_UI_ENABLED 앱 설정으로 숨긴다. 기존 QR 경로와 기능은 제거하지 않는다. 운영 config 파일을 수정하지 않았다.

Plugging 집계는 domain/plugging_summary.py에서 분리한다.
- 실제 완료: 등록된 운전 상태가 PLUGGED인 Tube.
- 기준 도달 대상: 실제 완료를 제외한 최근 검사 감육률 기준 이상인 Tube.
- 향후 예상: 실제 완료·기준 도달을 제외한 기준일 이후 예측 가능한 Tube.
- 기준일 누적 예측은 별도 명칭으로 유지하며 실제 작업 완료와 구분한다.
- 사용 중은 등록된 IN_SERVICE 상태만 집계한다. 미검사는 현재 설치기간에 결과가 없는 등록 Tube이며 운전 상태와 독립적이다. 미등록 수량은 현재 사양 수량에서 등록 수량을 뺀 값이며 상태 미확인이다.

DB 상태·계산식·스키마·운영 config는 변경하지 않았다.

검증: 관련 Python 시험 110건 및 JavaScript 연도별 Plugging/Critical 한도 회귀시험 통과.
브라우저: 실제 Jinja 템플릿과 모의 데이터로 운영 현황·정밀 분석·로그인을 1440/768/390px에서 확인. 열 경계·가운데 정렬·페이지 overflow·메뉴 접기·Escape 닫기 확인.
증거: reports/ui_usability/20261110/validation.json 및 PNG.
운영 DB와 E-131D 실제 레코드는 이번 작업에서 조회하지 않았다. 실제 0/기준 도달 5 사례는 단위시험으로 검증했으며 현장 인수검증과 구분한다.

변경 소스는 이관/소스/에 반영했으며 manifest.json에 해시, 이관안내_20261110.md에 운영 적용 위치와 주의사항을 기록했다. 운영 적용은 수행하지 않았다.

## 추가 변경: QR 관리자 전용 표시

이 항목은 앞의 QR 전체 숨김 및 QR_UI_ENABLED 복구 안내를 대체합니다. 로그인한 관리자 + 열교환기 조회 권한을 만족하면 QR 검색/스캔 및 QR 간편조회 진입을 표시합니다. 일반 사용자에게는 관련 버튼·모달·스캔 스크립트를 출력하지 않습니다. 기존 QR 경로와 권한 검사는 유지하며 DB/config 변경은 없습니다. 역할별 렌더링을 포함한 화면 관련 시험 12건을 통과했습니다. 운영 서버 적용 확인은 수행하지 않았습니다. 이관본의 최신 구성은 소스 42개 + 의존성 검토 2개이며 원본/사본 해시를 확인했습니다.
