## 집계 의미 재확인

- 실제 Plugging 완료 수량: 등록된 튜브 상태가 PLUGGED인 수량.
- Plugging 기준 도달 대상 수량: 실제 완료를 제외한 최근 검사 감육률이 설정 기준 이상인 수량.
- 향후 Plugging 예상 수량: 미완료·미도달 중 기준일 이후의 예상일을 계산할 수 있는 수량. 전체 Tube의 확정 작업 수량을 뜻하지 않음.
- 사용 중: 개별 등록 상태가 IN_SERVICE인 수량. 검사 여부와 별개.
- 미검사: 등록 Tube 중 현재 설치기간 검사결과가 없는 수량. 사용 중과 겹칠 수 있음.
- 등록되지 않은 튜브: 현재 사양 수량에서 개별 등록 수량을 뺀 값. 운전 상태·검사 여부 미확인. 사양 수량이 없으면 미확인으로 표시.
- 한도 미도달: 가용 예측 데이터에서 허용 수량 초과 시점을 얻지 못한 상태. 안전 판정·무한 수명·산정 불가와 구분.

## 실행 서버·실제 데이터 제한

- http://127.0.0.1:4824/api/health 및 /login 확인 시 URLError가 발생했다. 이 환경에서 실행 서버에 연결되지 않았으며, 서버가 중지됐는지 또는 접속 경로 문제인지는 확정하지 않았다.
- 별도의 START TRANSACTION READ ONLY / SELECT 1 연결 시도는 ValueError로 실패했다. 비밀값이나 원시 연결 오류는 출력하지 않았다. E-131D 실제 레코드를 조회하지 못했다.
- 서버 재시작·운영 배포·DB/config 변경은 수행하지 않았다.
- 따라서 운영 배포 완료, 실제 E-131D 수량 정합, 실제 로그인·권한 통과로 판정하지 않는다. 실행 환경이 준비된 뒤 로그인 → 운영 현황 → 정밀 분석 → E-131D 상세/튜브 관리/기존 QR 직접 주소를 같은 시점에 대조해야 한다.
