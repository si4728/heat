# 3D 튜브 선택 오류 수정

## 재현한 원인

3D 모드에서는 2D canvas가 hidden 상태이므로 clientHeight=0이다. selectTube가 draw2d를 호출하면 음수 scale로 원형 경계 반지름이 -36이 되어 Canvas arc에서 IndexSizeError가 발생했다. 선택 정보 일부만 바뀌고 updateThreeSelection 이후 단계가 실행되지 않아 3D 강조와 배지가 이전 튜브에 남았다. 앞선 선택 정보만 확인한 점검은 이 오류를 놓쳤다.

## 수정

- 숨겨졌거나 크기가 0인 2D canvas는 그리지 않으며 작은 캔버스에서도 scale을 양수로 제한한다.
- 선택 직후 3D 행렬·배지·화면을 갱신한다.
- pointerup을 window capture에서 처리하고 전체 이동량으로 회전과 클릭을 구분한다. 취소된 포인터는 선택하지 않는다.
- 실제 표면 raycast 우선, 하위 결함 mesh도 해당 튜브로 연결한다. 표면에 맞지 않으면 투영 축 8 CSS px 이내 가장 가까운 튜브를 선택한다.
- 튜브 직접 선택 목록과 배열 선택을 동기화한다. 단일 보기에서도 등록 튜브를 바꿀 수 있다. 미등록 위치 선택 시 배열로 복귀하며 물리 튜브로 생성하지 않는다.

## 검증

- 실제 브라우저에서 초기 2-4 → 목록 7-7 → 단일 보기 9-1 → 배열 복귀 → 배열 클릭으로 다른 위치 선택. 선택 정보·배지·목록의 동기화와 콘솔 오류 없음 확인.
- 실제 THREE 엔진을 이용한 raycast/5px 근접 클릭/빈 곳/영역 밖/회전·인출 및 숨겨진 2D 회귀 검사 통과: tests/test_tube_pick3d.cjs.
- 기존 초기 선택·2D 최근접 선택 검사 통과: tests/test_tube_selection.cjs.
