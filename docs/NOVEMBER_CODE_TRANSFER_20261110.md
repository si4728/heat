1. i-HMS 명칭 및 공통 화면 스타일.
2. 운영 현황 미등록 영역 정리와 데이터 입력 현황 이동, 잔여수명 7열 정렬·상태 분리.
3. 정밀 분석 공통 메뉴, 설비 선택, 접기, 현재 메뉴/설비 표시.
4. 실제 Plugging/기준 도달/향후 예상 구분, 예측률 분모, 미등록 평가 제외, 검사일/계산일과 실제 도달일 미상 안내.
5. Map 미등록 위치/등록 미검사 구분 및 감육률 범례.
6. Text-to-SQL, 검사 횟수 조회, 결과 상세 링크와 관련 권한·읽기 전용 연결.

## 적용 전 반드시 확인

- 현재 원본 app.py는 QR_UI_ENABLED=True이다. 이 패키지를 그대로 적용하면 관리자 및 열교환기 조회 권한이 있는 사용자에게 QR 메뉴를 표시한다. 전체 숨김 요청과 최신 요구사항 문서가 상충하므로 패키지에 현재 동작을 명시했으며 임의로 소스를 변경하지 않았다.
- Text-to-SQL은 운영의 sqlglot 의존성과 전용 SELECT 계정 설정 config/database-text-to-sql.conf, 해당 계정 권한 및 LLM 실행 환경 확인이 필요하다. 해당 설정·계정·모델은 이번 패키지에 포함하지 않는다.
- 의존성 검토 파일은 무조건 설치하지 않는다. 기존 운영 환경과의 차이와 복원 계획을 검토한다.
- 운영 DB 구조 호환성·실제 로그인·실 서버 접속·현장 UAT는 이번 파일 정리에서 확인하지 않았다. 사전 조건이 없는 기능을 운영 완료로 취급하지 않는다.
