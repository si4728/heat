# Text-to-SQL 도움말

질문창에 `도움말 알려줘`를 입력한 뒤 **SQL 생성** 버튼을 누르면 예시 질문 8개와 사용 방법이 표시된다. `도움말`, `도움말 보여주세요`, `사용법`, `예시 질문`, `샘플 질문`, `help`도 지원한다. 질문창 아래 도움말 예시 버튼으로도 입력할 수 있다.

예시는 검사 요약, 감육 상위 튜브, 감육 임계값별 튜브 목록, 공정별 교환기 수, 검사 횟수 순위, 기간 지정 질문이다. 예시를 선택하면 질문창에 입력된다. 사용자가 범위를 선택하고 다시 SQL 생성 버튼을 눌러야 조회 SQL이 생성되며 자동 실행하지 않는다.

도움말 자체는 설비·공정 선택이 필요 없다. 기존 Text-to-SQL·검사 조회 권한과 CSRF 검사를 유지하며 모델 호출, 업무 데이터 조회, SQL 생성·실행 토큰 발급은 하지 않는다. 인증·권한 확인 및 사용 로그 기록은 기존과 동일하다. 로그 유형은 `help`다. 도움말 요청 시 화면의 이전 SQL·결과·차트를 초기화하고 복사·실행 버튼을 비활성화한다.

검증: 관련 웹·범위·로그 테스트 101건 통과. 실제 Edge의 PC·태블릿·모바일 화면에서 도움말 출력, 선택한 예시 입력 및 포커스 이동, 기존 SQL 초기화와 대기 아이콘 종료를 확인했다. 브라우저 응답은 고정 예시로 대체했으며 모델을 호출하지 않았다.
