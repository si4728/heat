# IRIS 검사 횟수 질문 인식

요청 문장: “최근 iris 검사를 제일 많이 수행한 열교환기를 리스트해줘”.

열교환기별 기간 내 IRIS 검사 회차 수를 집계하는 유형으로 구현했다. 기본 최근 5년·상위 20대이며 최근 N년·올해·작년과 상위 N대(1~100)를 지원한다. 최근 5년은 현재 한국 날짜에서 5년 전 같은 날부터 오늘까지다. 조회 범위를 지정하지 않으면 VCM1·VCM2 전체, 지정하면 해당 설비·공정만 적용한다. 회차 선택은 이력 순위에 영향을 주지 않는다.

기간 내 미대체 IRIS 검사 ID를 각각 1회로 세므로 Tube 건수와 구분된다. 최신 회차 중복 여부로 설비를 제외하지 않는다. 날짜는 검사일 우선·보고일 대체이며 둘 다 없는 회차는 제외된다. 횟수 동률은 최근 검사일·설비 ID로 정렬한다. 생성 SQL과 기간을 미리 확인한 뒤 실행할 수 있다.

고정된 질문 유형은 서버의 SQL 템플릿으로 처리하고 임의 모델 SQL의 JOIN 허용 범위는 확장하지 않았다. 기존 인증·CSRF·서명 토큰·15분 만료·실행 시 권한 재검사·SELECT 전용 계정·5초 제한을 적용한다.

## 검증

- 전체 공식 회귀시험 184건 통과, 실패·오류·건너뜀 0.
- 실제 MariaDB 시험 5건 통과. 신규 순위 결과를 독립적으로 조회한 검사 이력의 Python 집계·정렬 결과와 대조했다.
- 기간·윤년·행수·범위·SQL 변조·권한·읽기 계정 검증 및 웹 회귀시험 15건 통과. 기존 SQL 단위시험 14건 통과.
- Chrome에서 실제 요청 문장·범위 미선택·생성 SQL·기간·실제 결과·최근 3년/상위 5대 검증. 1440·768·390px 가로 넘침 없이 표시. 브라우저 9항목 통과, 스크린샷 확인.

증거: `reports/text_to_sql/frequency-20261109/`. 운영 데이터와 스키마는 변경하지 않았다. 운영 서버는 재시작하지 않았다. 적용에는 운영 웹 서버 재시작이 필요하다. 기존 GGUF 모델 추론은 변경하지 않았으며 새 순위 질문은 모델 호출 없이 처리한다.
