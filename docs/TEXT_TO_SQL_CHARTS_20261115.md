# Text-to-SQL 조회 결과 차트

기존 조회 결과 표 아래에 막대, 파이, 선 그래프를 추가했다. 차트 유형, 분류 기준, 수치 항목을 선택할 수 있다. SQL 생성·실행 및 권한 검사 흐름은 유지하며 추가 SQL이나 모델 호출은 하지 않는다.

- 차트는 현재 표에 반환된 행만 사용한다. 조회 제한에 도달한 경우 표시하며 전체 DB의 분포로 해석하지 않도록 안내한다.
- 막대는 유효한 수치를 표시한다. 결측값과 0을 구분하고 음수를 지원한다.
- 파이는 검사 횟수·튜브 수 등 건수 항목만 지원한다. 음수 또는 양수 합계가 없는 결과는 사용할 수 없다. 5개를 넘는 항목은 상위 4개와 나머지 합계로 표시한다.
- 선 그래프는 날짜 또는 연도별 한 행인 결과만 지원한다. 날짜순으로 정렬하며 결측 구간을 연결하지 않는다. 동일 날짜의 중복 행은 자동 합산하지 않는다.
- 새 조회, 질문·범위 변경, 조회 실패 시 이전 차트를 비운다. 차트 오류가 SQL 실행 성공 여부를 바꾸지 않는다.

## 검증

- `tests/test_text_to_sql_charts.cjs`: 수치 판별, 식별자 제외, 결측/0, 파이 합계 보존, 날짜 정렬과 중복, 원본 불변성 검사 통과.
- `tools/verify_text_to_sql_charts_browser.mjs`: 실제 템플릿과 Edge에서 1440/768/390px 검증 통과. 응답은 고정 데이터로 대체하며 모델 호출과 DB 쓰기는 하지 않는다. 막대·파이·선 전환, 빈 결과·실패 처리, 입력 변경, 안전한 텍스트 표시, 가로 넘침을 확인했다.
- 기존 Text-to-SQL MariaDB/web/scope/usage-log 테스트 82건 통과.
- 변경 소스의 디자인 lint: FAIL 0, WARN 0. 전체 페이지 검사에서는 기존 공통 메뉴의 화면 가장자리 여백·텍스트 겹침 및 기존 링크·제목 크기 항목이 검출됐다. 전체 페이지 검사 통과로 간주하지 않으며, 공통 메뉴 변경은 이 작업에 포함하지 않았다.

차트 순수 테스트는 Node.js로 `node tests/test_text_to_sql_charts.cjs`, 브라우저 검증은 `node tools/verify_text_to_sql_charts_browser.mjs`로 실행한다. 브라우저 검증에는 프로젝트의 `.venv/Scripts/python.exe`, 로컬 MariaDB의 활성 관리자 조회 및 Edge가 필요하다. 캡처와 검증 결과는 무시되는 `tmp/text-to-sql-charts/`에 저장한다.
