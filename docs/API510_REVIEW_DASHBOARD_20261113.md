# API 510 검토·승인 대기 대시보드

관리자가 대시보드에서 검토 요청된 계산결과를 발견하고 해당 승인 화면으로 이동할 수 있도록 최하단에 대기 목록을 추가했다. 최근 검사·예정 검사 영역 다음에 표시한다. 기존 대시보드 범위인 VCM1·VCM2만 포함한다. PE 등 다른 공정으로 범위를 확장하지 않았다.

- `SUBMITTED` 계산결과만 계산 ID별로 집계한다. `DRAFT`, `REJECTED`, `APPROVED`는 제외한다.
- 전체 대기 건수와 요청일이 오래된 순서의 최대 10건을 표시한다. 요청일이 없으면 생성일을 정렬에 사용한다.
- 공정, 열교환기번호, 부품, 계산 ID, 계산 생성자, 검토 요청일시를 표시한다. 생성자를 요청자로 오인하지 않도록 구분했다.
- 검토·승인 링크는 해당 설비의 API 510 관리 화면에서 정확한 계산결과 행으로 이동한다. 대시보드 자체에서 승인하지 않는다.
- 승인·반려 후 대시보드를 다시 조회하면 해당 결과는 목록과 건수에서 제외된다. 실시간 푸시 알림이나 자동 새로고침은 추가하지 않았다.
- 일반 사용자에게는 목록을 표시하지 않고 추가 조회도 실행하지 않는다. 실제 승인 경로의 관리자 제한은 유지한다.
- 대기 0건은 숫자 0과 빈 상태 안내를 표시한다. 모바일에서는 필드를 세로로 배열해 승인 화면 링크까지 가로 스크롤 없이 접근할 수 있다.

기존 요청에 따른 API 510 버튼 문구 `계산서 생성` → `계산결과 생성` 변경도 유지한다.

검증: 관련 테스트 12건 통과. 현재 MariaDB의 VCM1·VCM2 승인 대기 건수는 0건이며 독립 SQL과 대조했다. 대기 샘플 및 빈 상태를 DB 쓰기 없이 렌더링하여 Edge에서 1440·768·390px로 확인했다. 화면 샘플은 `tmp/api510-dashboard-preview`에만 저장했다. Node가 없어 스킬의 Node 기반 검사기는 실행하지 못했으며 Edge 개발자 도구로 뷰포트와 넘침을 확인했다. 운영 서버 재시작 및 GitHub 게시는 수행하지 않았다.
