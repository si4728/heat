# 고객 개선 요청 확정 사항

고객 요청 원문: `docs/review_20261112.docx`.

## D01 대시보드 생산팀 집계

- 확정일: 2026-11-12.
- 상태: 생산팀 합산·공정 별도 표시 구현 및 검증 완료, 운영 적용 대기.
- 결정: 대시보드에서 VCM1·VCM2를 **VCM 생산팀으로 합산**하고 **공정은 별도로 표시**한다.
- 적용 범위: VCM1·VCM2. 그림에 등장하는 다른 생산팀으로 범위를 확대하지 않는다.
- 조직 처리: 기존 VCM 생산팀 코드와 설비의 생산팀·공정 정보를 활용한다. 이 결정만을 이유로 새 생산팀이나 공정을 생성하거나 기존 소속을 변경하지 않는다.
- 집계 처리: VCM 생산팀 집계 대상은 VCM1·VCM2 소속 대상 설비의 합집합이며 동일 설비를 중복 집계하지 않는다. 합산 외의 개별 지표 정의는 별도 확정 사항을 따른다.
- 표시 처리: 생산팀과 공정을 서로 다른 구분으로 표시하고 공정값은 기존 등록 정보를 사용한다.
- 검수 기준: 같은 대상·필터에서 VCM 생산팀의 설비 수가 VCM1·VCM2 설비 수 합계와 일치하고, 상세 목록에서 각 설비의 공정을 식별할 수 있어야 한다.
- DB 변경: 이 결정에 따른 테이블·필드 추가는 필요하지 않다. 운영 DB의 조직 코드·소속 값 누락은 적용 전에 별도로 확인한다.
- 고객 문의: 생산팀 집계 범위를 다시 선택하도록 묻는 질문은 해결된 항목으로 제외한다.
- 추가 확정: 대시보드 QR 항목은 설정·역할에 관계없이 숨긴다. 기준일부터 잔여기간 30년을 초과하는 도달 예상과 30년 초과 예상 잔여수명은 ‘30년 이상’으로 표시한다. 정확히 30년이면 원래 표시를 유지한다. 계산값·구간 분류는 변경하지 않는다.
- 구현·검증: [대시보드 반영 기록](DASHBOARD_TEAM_20261112.md).

## D02 최초 튜브 기준 도달 예상

- 확정일: 2026-11-12.
- 상태: 대시보드 설비 목록에 구현, 운영 서버 적용 대기.
- 표시 명칭: **최초 튜브 기준 도달 예상**. 고객 문의에서 사용한 모호한 표현인 '대표 최초 도달일'을 이 명칭으로 대체한다.
- 의미: 해당 열교환기의 실측 튜브별 예측에서 Plugging 감육률 기준에 가장 먼저 도달할 것으로 예상되는 날짜 또는 연도이며, 해당 튜브 식별자를 함께 표시한다.
- 구분: 실제 Plugging 작업일이나 전체 튜브의 허용 수량 한도 도달일을 뜻하지 않는다. 통계 추정 최대 감육률의 도달일은 별도 항목으로 구분한다.
- 계산 기준: 적용 감육속도, 예측 시작일 및 임계값은 별도 확정 기준을 따른다. 이 결정은 기존 계산식이나 운영 기준값을 변경하지 않는다.
- 현황: 대시보드 설비 목록에 도달 예상일과 튜브 번호를 추가했다. 기존의 '한도 최초 초과' 잔여수명 항목은 유지한다. 실제 Plugging 완료 튜브는 제외하고, 검사 시 이미 기준에 도달한 경우 확인 검사일과 상태를 표시하되 알 수 없는 최초 도달일을 만들어 표시하지 않는다. 예측할 데이터가 없으면 산정 불가로 표시한다.
- 검수 기준: 튜브별 유효 도달 예상일 중 가장 빠른 날짜와 일치하고, 실측 기반 최초 도달과 통계 추정·허용 수량 한도·실제 작업일이 구별되어야 한다.
- 개발 검증: 대시보드·기존 예측·계산 경계 Python 시험 37건 및 연도별 Plugging·튜브 선택 JS 시험 통과. 개발 DB 조회 결과로 만든 화면을 1440/768/390px에서 확인했고, 새 열의 표시 및 표 내부 가로 스크롤을 검증했다. 기존 디자인은 유지했으며 실제 운영 서버 적용은 별도이다.

## D03 검사 표본 기반 최대 감육률 추정

- 확정일: 2026-11-12.
- 상태: 사용자 요청에 따라 정밀 분석·열교환기 상세에 구현, 운영 서버 적용 대기.
- 결정: 그림 5의 확률 변환·직선 회귀로 전체 최대 감육률과 상위 20% 경계 감육률을 추정하고 최초 Plugging 기준 도달 예상 연도 및 20% 도달 예상 연도를 계산한다.
- 필수 기준: 유효 표본 10본 미만이면 표본 부족과 기존 실측 예측 유지, 추정 감육률 상한 100%, 실측 최대·추정 최대 동시 표시.
- 기존 기능: 실측 튜브별 예측과 대시보드 최초 튜브 도달은 유지한다. 허용 수량 비율은 아래 D09의 고객 추가 확정 기준으로 대체한다.
- 계산·예외·수량 출처·검증 결과: [구현 기록](SAMPLE_WALL_LOSS_ESTIMATE_20261112.md).

## D04 검사 이력 및 차기 검사 권고 계획

- 확정일: 2026-11-12.
- 상태: 사용자 요청에 따라 연도별·공정별 이력과 권고 계획 목록·같은 행 등록 구현, 운영 적용 대기.
- 결정: 이력은 두 화면으로 제공하고 기본 검사계획 화면에는 차기 검사 권고 설비만 표시한다. 기존 계획 관리·승인·진행 이력은 별도 접근 경로로 보존한다.
- 등록 방식: 같은 행에서 예정일과 실제 대상 Tube를 선택한다. 기존 실제 대상 저장 구조를 활용하므로 DB 스키마 변경은 없다.
- 권고 기준: 고객 확정에 따라 **실측 튜브의 최초 도달일**로 고정한다. 최근 검사일에 도달일까지 기간의 1/2을 더하며 통계 추정일로 대체하지 않는다. 화면과 등록 검증에 동일하게 적용한다.
- 집계·권한·등록·시험 근거: [구현 기록](INSPECTION_HISTORY_PLANS_20261112.md).

## D06 메뉴 정리

- 고객 그림 1에 따라 일반 메뉴를 대시보드·열교환기 목록·열교환기 분석·검사 이력·검사계획 다섯 개로 정리했다. 검사 이력 아래에 연도별·공정별을 둔다.
- 데이터 적재·품질·사용자·조직 코드·DB 점검·백업은 상단 관리자 설정에 배치하고 기존 서버 권한을 유지한다.
- 등록·Excel은 목록 화면 버튼으로 제공하며 목록의 코드·설비명 클릭은 해당 설비의 분석 화면으로 연결한다.
- 추가 사용자 확정: Text-to-SQL 진입은 공통 상단의 작은 `LLM` 버튼으로 제공한다. 관리자 계정에만 표시하며 `관리자 설정` 바로 왼쪽에서 같은 줄을 유지한다. 분석 화면의 기존 중복 Text-to-SQL 버튼은 제거한다. 기존 Text-to-SQL 서버 접근 권한 검사는 유지한다.
- 추가 표시 확정: LLM과 관리자 설정은 같은 크기의 아이콘 버튼으로 통일한다. LLM은 AI 대화(말풍선·별), 관리자 설정은 톱니바퀴 아이콘을 사용한다. 데스크톱·태블릿 36×36px, 모바일 44×44px이며 툴팁과 접근성 이름을 제공한다. 실제 1440/768/390px 화면에서 크기·정렬·메뉴 열기·Escape 닫기·Text-to-SQL 이동을 확인했다(`reports/llm-icons-20261112/validation.json`).
- 구현·검증: [메뉴 정리 기록](MENU_CLEANUP_20261112.md). 운영 적용 대기.

## D07 적용 감육속도 선정 — 고객 추가 회신 확정

- 확정일: 2026-11-12. 기존의 장기 평균만 사용하던 기준을 대체한다.
- 같은 튜브의 현재 설치 이후 유효 측정일이 3회 이상이면 두께(mm)와 경과연수의 최소제곱 선형 회귀를 구하고, 두께 기울기에 음수를 곱한 감육속도를 적용한다. 장기값이 더 크더라도 양의 회귀값을 우선한다.
- 유효 측정일이 2회 이하이면 양수인 단기·장기 감육속도 중 큰 값을 적용한다. 한 번만 측정했거나 단기값을 계산할 수 없으면 유효한 양의 장기값을 사용한다.
- 3회 이상에서 회귀값이 0 이하이면 장기로 전환한다. 2회 이하에서 단기값이 0 이하이면 장기로 전환한다. 적용 대상 추정법을 기준으로 판단하므로, 3회 이상에서 회귀값이 양수이면 마지막 두 측정의 단기값이 음수여도 회귀값을 사용한다. 장기값도 양수가 아니면 산정 불가이다.
- 산정 근거: `추세(n회)`, `단기`, `장기`, `단기 0 이하 → 장기`, `추세 0 이하 → 장기`. 회귀 연산이 유한하지 않은 경우는 `추세 산정 불가 → 장기`로 구분한다.
- 회차 집계: 같은 날짜의 중복 결과는 최소 유효 두께 한 건으로 계산한다. 무효·대체된 검사, 설치·교체 이전 측정, 미래 회차는 회귀와 단기 선정에서 제외한다. 설치일의 가정상 공칭두께를 실제 검사 횟수에 넣지 않는다.
- 단기·장기·회귀 원값과 선정 근거는 배율 변경으로 바뀌지 않고, 선정값에만 배율을 적용한다. 기존 예측 기준일은 변경하지 않는다.

## D08 전체 튜브 수량 — 현재 승인 설계 수량

- 현재 승인 사양(`heat_exchanger_spec_revision.is_current=1`)의 `tube_count`만 전체 튜브 수와 허용 수량·표본 추정의 분모로 사용한다.
- 보고서 수량, Bundle 예상 수량, 등록 튜브 수는 승인 설계 수량을 대체하지 않는다. 승인 수량이 없으면 전체 허용 수량과 설비 잔여수명은 산정 불가이며, 유효 실측 튜브의 개별 예측은 별도로 유지한다.
- 운영 DB의 사양 수량은 변경하지 않는다.

## D09 허용 Plugging 비율 — 일반·Critical 모두 20%

- 고객 회신에 따라 VCM1·VCM2의 기본 허용 비율은 일반·Critical 모두 20%로 적용한다. 중요도 자체는 변경하지 않는다.
- 중요도별 비율은 `hx_configuration.conf`의 `[remaining_life] normal_allowable_plugging_percent`, `critical_allowable_plugging_percent`로 관리한다. 두 값의 초기값은 모두 20이며 향후 승인에 따라 1~20의 정수로 변경할 수 있다. 설정 변경은 애플리케이션 재시작 후 적용된다.
- 계산과 관리 입력 화면은 동일한 설정값을 사용한다. 과거 중요도 기준으로 DB에 자동 저장된 10%를 새 기준으로 오인하여 읽지 않는다. 설비를 저장하면 관리기준 비율도 현재 설정값으로 기록한다. 기존 DB 값을 일괄 변경하지 않는다.
- Simulation의 명시적 비율 비교는 유지한다. 기본 허용 수량은 승인 설계 수량 × 비율을 내림한 값이며, 기존의 ‘허용 수량 최초 초과’ 판정은 유지한다. 감육률 기준 40%와 허용 수량 비율 20%는 서로 다른 기준이다.
- 구현·검증: [추가 회신 반영 기록](REVIEW_20261112_RATE_IMPLEMENTATION.md).

위 추가 회신은 개발 코드에 반영한다. 운영 서버 재시작·배포와 업무 DB의 일괄 변경은 별도로 수행하지 않았다.
