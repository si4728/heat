# API 510 / ASME VIII 계산 엔진 검산 관리

- 시스템 계산 버전: ASME 1.0.0 / API510 1.0.0
- 적용 DB 스키마: 3.8.0
- 현재 검증 상태: 내부 수식 회귀시험 완료, 공인검사자 또는 압력용기 책임 엔지니어 승인 대기

## 내부 검증 범위

`test_data/api510_validation_cases.json`은 원통 Shell, 구형 Shell, 표준 2:1 타원형 Head, 반구형 Head의 내부압력 필요두께 및 MAWP 수식 회귀시험을 관리한다. 이 자료는 소프트웨어 회귀시험이며 공인 설계검산서를 대신하지 않는다.

## 승인 기준

1. 입력 단위와 코드 판본이 일치해야 한다.
2. 허용응력과 용접효율은 승인된 설계자료에서 추적 가능해야 한다.
3. `t_required`, MAWP, 잔여수명 및 다음 검사일을 독립 계산서와 비교한다.
4. 차이가 있으면 원인과 허용 여부를 기록하고 소프트웨어 버전을 변경한다.
5. 시스템의 `APPROVED` 전이는 권한 있는 검토자만 수행한다.
