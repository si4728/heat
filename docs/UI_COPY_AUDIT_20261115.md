# 화면 문구 점검 결과

2026-11-15. GitHub main의 8b93aa1 기준으로 업무 코드, 템플릿 및 화면 스크립트를 검색하고 현재 등록된 화면을 실제 요청했다. 기능 완성도 검증이나 모든 데이터·권한 조합의 UI 검증과는 구분한다.

## 범위와 결과

- 자사 Python/HTML/JavaScript 소스 195개 파일에서 확인·점검·검토 및 개발 미완성 관련 표현 187곳을 검색했다. 보관된 legacy 코드, 테스트·도구 및 외부 vendor 코드는 운영 화면 판정에서 제외했다.
- 관리자 인증 세션으로 화면 44개를 GET 요청해 모두 HTTP 200을 확인했다. 응답의 텍스트에서 개발 중·준비 중·미구현·추후 제공 등의 명시적 미완성 문구는 검출되지 않았다. HTML 요청 검사이며 JavaScript의 모든 상호작용을 실행한 검사는 아니다. 동적 화면 스크립트는 소스 검색에 포함했다.
- 작업지시 상세는 표본 ID를 지정하지 않아 요청하지 않았다. 소스 템플릿은 검색했다. PDF·파일 다운로드, API, 내보내기와 POST 업무 처리는 화면 요청 검사에서 제외했다. 데이터를 등록하거나 업무 승인 상태를 변경하지 않았다.
- 모든 Jinja 템플릿 56개 구문 검사, API 510 관련 테스트 9건, `git diff --check` 통과.

## 수정 사항

| 위치 | 기존 표현·문제 | 반영 내용 |
| --- | --- | --- |
| `templates/iris2_status.html` | 개발 상태, 호환성 검증 후 순차 연결 | 시스템 안내와 현재 권한별 업무 메뉴 설명으로 교체. 현재 등록 라우트에서 이 템플릿을 사용하지 않으므로 실제 노출된 화면으로 집계하지 않았다. |
| `templates/tube_layout_revisions.html` | 관리 화면이라는 제목과 별도 확인 후 승인·반영한다는 안내가 제공 기능을 모호하게 설명 | 조회 화면으로 명시하고 원천 좌표·승인 상태·Tube 연결 현황을 조회하는 기능을 설명. 이 화면에 승인·좌표 변경 기능이 없다는 사실은 유지했다. |
| `templates/api510_management.html`, `templates/api510_settings.html` | 기존 버튼은 계산결과 생성이나 안내·빈 상태에는 계산서 생성 표현이 잔존 | 계산결과 생성으로 통일하고 초안·검토 요청·승인 상태의 의미를 설명. 실제 설계근거 확인 및 승인 조건은 유지했다. |

## 유지한 정상 표현

- 비밀번호 확인, 대화상자의 확인 버튼, 상세·근거 확인 링크: 사용자의 정상 조작이다.
- DB 상태 점검, 백업 복원 검증: 실제 관리자 기능이다.
- 설계근거 확인, 검토 요청, 승인 대기, ML 전문가 검토: 업무 절차나 분석 결과의 사용 범위이며 개발 미완성 상태가 아니다.
- 수량·설치일·측정값 확인 필요, 미등록·미확인, 산정 불가: 원천 데이터의 상태와 산정 한계를 알린다. 완료·정상으로 바꾸지 않았다.
- ML 검토지원 전용, 자동판정 비활성: 현재 기능 범위이다. 자동판정이 구현·승인됐다는 의미로 바꾸지 않았다.

재현: `.venv/Scripts/python.exe tools/audit_ui_copy.py --render`. 상세 검색과 요청 결과는 무시되는 `tmp/ui-copy-audit.json`에 저장된다. 단순 키워드 검출은 미완성 기능의 자동 판정이 아니며 문맥 검토가 필요하다.
