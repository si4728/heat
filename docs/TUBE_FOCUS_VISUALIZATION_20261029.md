# 단일 튜브 위치·감육 시각화

## 적용

- 3D 단일 보기: 실제 길이 단위 mm 눈금, 결함 위치·감육률·실측/대표 라벨, 대표 위치 점선 테두리.
- 단일 보기 아래: 길이별 위치 막대, 클릭/키보드로 결함 위치에 초점 이동, 기준 두께 대비 최소 잔존 두께 개념도, 상세 위치 목록.
- mm 저장값을 사용하며 음수·범위 밖·길이 미등록 위치를 끝점으로 강제 이동하지 않는다.
- 원주각 미등록 띠는 원주 전체 부식을 뜻하지 않으며, 띠 폭은 결함 길이를 모를 때 가시성용이다. 기준방향 미등록은 그대로 표시한다.
- 실측/대표 위치 구분, 미등록 영역 중립 회색 유지, 물리 DB·수명 계산 변경 없음.
- Sprite 텍스처를 튜브 전환 시 해제하며 배열·2D 복귀 시 비교 패널을 숨긴다.

## 실제 데이터 확인

E-106 Tube 13-14 (tube_id 1971): 길이 6,000mm, 공칭 2.11mm, 감육률 91.47%, 최소두께 0.18mm, 깊이 1.93mm, 대표 위치 839mm. 길이의 14.0% 지점, 잔존 8.53%. 기준방향·원주각 미등록. 839m가 아닌 mm 저장값이다.

Tube 15-13은 별도 튜브로 감육률 40.28%, 최소두께 1.26mm, 위치 936mm이다. 사용자 제시 91.47% 값과 혼용하지 않았다.

## 기능 검증

- 실제 브라우저: 단일 보기 생성, 839mm/14.0%/8.53% 표시, 위치 마커 클릭, 단일 보기 상태에서 15-13으로 변경(936mm/15.6%/잔존59.72%), 배열 복귀 시 비교 패널 숨김, 콘솔 오류 없음.
- Node: 6,000mm 사례, 1,000,000mm 장축, 양 끝, 누락·음수·범위 밖, 대표/실측·원주각, 불가능한 두께 검사 통과 (`tests/test_tube_focus_data.cjs`).
- 실제 THREE 선택 및 숨김 2D 회귀 검사 통과. Python 기존 121개 전체 테스트 통과.
